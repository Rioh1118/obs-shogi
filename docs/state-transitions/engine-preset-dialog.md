# 状態遷移表: プリセット編集ダイアログ（下書きと取得）

対象: `src/features/settings/model/presetDialogReducer.ts`（`presetDialogReducer`）。
呼び手は `EnginePresetEditDialogPanel`。画面の仕様は `docs/spec/screens/engine-preset-dialog.md`。

ダイアログを閉じると部品ごと外れる（`EnginePresetEditDialogPanel` が `open` でないとき描かない）ので、
「閉じている」状態はこの表に無い。閉じた後に返った取得の結果は、外れた部品の `dispatch` へは届かない
（Rust の取得は止まらない。`probeEngine` の doc）。

| P0   | 取得なし | `probe === null` |

R1 のセルだけ、もう1つの軸で動きが分かれる: **下書きのエンジン = 取得したエンジンか**。判定は
`withDefinitions` の中（`probePathOf(draft.enginePath) === outcome.enginePath`）で、reducer は同じ参照が
返ったか（`withDefs !== cur`）で受け取る。定義がいまのエンジンのものか（`hasCurrentDefinitions`）は
reducer は見ない——見るのは表示の側（`optionRows`・`valuesWithoutField`・`probeStatusText`）。

## 不変条件

1. 下書きへ定義を入れるのは、いま待っている取得の結果で、下書きのエンジンがその取得のエンジンのときだけ
2. 定義に当てるのは当てる元の値（開いたときの値＋このダイアログでの編集）。当てた後の下書きから当て直さない
3. 取得中は保存できない（`probe !== null`。呼び手が保存を塞ぐ）。取得中の印を下ろせるのは結果・失敗・「やめる」だけ
