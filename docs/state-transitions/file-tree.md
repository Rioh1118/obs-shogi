# 状態遷移表: file-tree（L1）

対象: `src/entities/file-tree/model/provider.tsx` と `src/widgets/file-tree/ui/FileTree.tsx`。

上位は [app.md](app.md)。棋譜そのものの読み込みは `game.md`（未作成）が持つ。

## 状態

ツリーとファイル操作に関わるものだけ。選択・展開・メニューは失敗経路に関わらないので省く。

| 記号   | 状態               | 判定                                                            |
| ------ | ------------------ | --------------------------------------------------------------- |
| **S0** | ルート未設定       | `rootDir === null`。`loadFileTree` は即 `Ok` を返して何もしない |
| **S1** | 読み込み中         | `isLoading === true`、`error === null`                          |
| **S2** | 読み込み済み       | `fileTree !== null`、`error === null`                           |
| **S3** | **ツリーが消えた** | `error !== null`。`FileTree.tsx:133` が `undefined` を返す※1    |
| **S4** | 同名の衝突         | `conflict !== null`。`ConflictDialog` が出る                    |
| **S5** | 棋譜が開けなかった | `kifuError !== null`。`KifuReadErrorDialog` が出る              |

**S3 と S5 は別のフィールド**（`error` と `kifuError`）で、出口も別。
`error` の読み手は `FileTree.tsx` だけ、`kifuError` の読み手は `AppModalLayer` だけ。

### 注

※1 **S3 ではファイルツリー全体が描画されない。**

```
if (error) {
  console.error("再読み込み", error);
  return;              // widgets/file-tree/ui/FileTree.tsx:133
}
```

何が失敗したかは画面に出ない。ツリーが消えるので、**ツリーからの操作が全部できなくなる**。
→ [failure-surfacing.md](failure-surfacing.md) F-3

※2 `handleFailure` が `already_exists` 以外を全部 `pushError` に流す
（`provider.tsx` の `handleFailure`）。**作成・リネーム・削除・移動の失敗が、
どれもツリーを消すという同じ結末に落ちる。** 失敗の種類は `FsError` に入っているが使われていない

※3 **S3 からの復帰は E1（ルートの再設定）だけ。**
`clearError` と `refreshTree` は context に公開されているが、
**UI 側の呼び出し元が0**。設定画面からワークスペースを選び直せば戻れるので
完全な行き止まりではないが、**「ツリーが消えた」から「設定を開いて選び直す」に
たどり着く導線は無い**

## この表が満たすべき不変条件

1. **ツリーが表示されているなら、それはディスクの現在の状態と一致している。**
   ファイル監視が無いので、外部からの変更に対してはこれを守れていない
2. **どの失敗からも、利用者の操作で S2 に戻れる。** ※3 が破っている
3. **`error` と `kifuError` は独立。** 棋譜が開けなくてもツリーは操作できる（S5 の行）

## 埋まっていないセル

- **`(S2, E9)` → S3 の遷移全体。** 作成・リネーム・削除・移動の失敗が
  ツリーを消すことを固定しているテストが無い。**`entities/file-tree` に `__tests__` が無い**
- `(S3, *)` S3 に入った後の全ての操作
- `(S4, E1)` 衝突ダイアログを開いたままルートが変わる
- **外部でのファイル変更**（機能自体が無い）
