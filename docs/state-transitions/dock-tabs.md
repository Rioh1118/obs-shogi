# 状態遷移表: ドックのタブ × 解析

対象: これから作るドックのタブ（#562）と、既にある
`src/entities/analysis/model/provider.tsx` ／ Rust 側 `src-tauri/src/engine/bridge.rs`。

決定は [ADR-0010](../decisions/0010-dock-tabs-and-view-vocabulary.md)。
解析そのものの遷移は [analysis.md](analysis.md) が持つ。ここはその上に
**「どのタブを見ているか」を重ねた表**で、解析の内部（S2〜S6）は写さない。

**この表は3つの状態機械をまたぐ。** 見ているタブ・フロントの解析状態・Rust のセッション。
3つ目を列に入れ忘れたことが #120 のラウンド3 BLOCK を生んだ、と `analysis.md` が書いている。

## 注

1. **T0 から出るときに開くタブ**は、設定「起動時に開くタブ」が決める
   （前回のもの / 固定）。`T0` の間はタブ列ごと出ない。
2. **★1 —— 候補手は直した（#561）。経過時間はまだ消える。**
   候補手のキャッシュは `AnalysisProvider` が持つので
   （`entities/analysis/lib/candidateCache.ts`）、解析ビューが unmount されても残り、
   戻ってきたときに離れる前の候補手が出る。
   **残っているのはヘッダの経過時間。** `AnalysisPaneHeader` の `startTimeRef` は
   ビューごとの `useRef` なので、作り直されると `isAnalyzing` が立ったままでも
   `Date.now()` で引き直され、**走り続けている解析の経過が 0s に戻る。**
   不変条件2（表示の切替でデータを失わない）を破る。→ **#566**
3. **★2 —— 棋譜が交代しても解析は止めない。** キャッシュは
   `candidateCache` の `scopeTo` が前に宣言された棋譜と突き合わせて破棄し（宣言するのは
   `AnalysisPane`、持ち主は `AnalysisProvider`）、局面は
   [engine-position-sync.md](engine-position-sync.md) が新しい盤面へ送り直す。
   **セッションは残らない。** タブ化とは独立。
4. **★3 —— Rust のセッションが残る。** ドックごと消えてもフロントは
   `stopAnalysis` を投げない。**いま到達できない**（注6）が、対局タブ（#284）を
   入れると踏む。→ **#441**（同じ不変条件。引き金が違う）
5. **★5 —— 破棄は次に解析タブを開いた回まで遅れる。** `scopeTo` を呼ぶのは
   解析ビューなので、`Tx`（解析タブを見ていない）では呼ぶ者が居ない。
   持ち主は provider 側なので控えは残り続け、戻ってきた回に捨てられる。
   **取り違えは起きない**——鍵に棋譜の識別子が入っているため（ただし鍵そのものが
   盤と食い違う経路は別に在る → #568）。

6. **K2 はいま起きない —— この主張は現物と違う（→ #570）。** 以下はそのままにしてあるが、
   `reset_state` が `jkf` を `null` に戻し、`GameFileTreeBridge` が撃つ経路が在る。
   書き替えると ★3 と #441 の範囲まで動くので、判断ごと #570 で扱う。 `hasKifu` は `entities/game` の `GameView` が
   `player` から導いていて、**`jkf` を `null` に戻す action が reducer に1つも無い**
   （`jkf` を書くのは `jkf_replaced` と `jkf_restored` ほかで、どれも非 null を入れる）。
   `null` は初期状態だけが持つ。
   **消さずに表に残す** —— 対局を入れた回に、ここが最初に生きるセルになる。
7. **★4 —— 開始・停止の口は解析タブの操作列にしかない。** これは仕様として決めてよい。
   キーボードショートカットを足すなら、**押した時点で解析タブへ移る**のが自然。

## 不変条件

1. **表示の切替は、解析の実行状態を変えない。** タブを移っても表示モードを変えても
   `isAnalyzing` と Rust のセッションは動かない
2. **表示の切替でデータを失わない。** 戻ってきたとき、離れる前に見えていたものが
   （より新しいものが無ければ）そのまま見える
3. **Rust のセッションを終わらせられるフロントが、必ず1つは生きている。**
   「読み手が居なくなったら止める」ではない —— タブを移っただけで止めると 1 を破る

## 埋まっていないセル

**全部。** 実装がまだ無いので、テストが踏んでいるセルは1つも無い。

#562 で器を作るときに、セルごとの印と、そのセルを壊す変異で落ちることの確認を足す。
**それまでこの表を「検証済み」と読まない。**
