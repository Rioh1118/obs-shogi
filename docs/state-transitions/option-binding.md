# 判定表: 評価関数・定跡の流し先（束縛）

対象: `src-tauri/src/engine/binding.rs`（`bind`）。呼ぶのは解析の起動
（`src-tauri/src/engine/analyzer.rs` の `start_engine_steps`）。

**入力はその回の申告**（`usi` への応答の `option` 行）と、画面が渡すパスと利用者の値、呼び手の方針
（固定値）だけ。**実行ファイル名は見ない**——同じ名前の別のエンジン、名前を変えたエンジンで食い違う。
画面（TS）は USI の名前を組まない（`src/__tests__/usiNamesStayInRust.test.ts` が見る）。

## 評価関数（上から最初に当たった行）

**評価関数を選んでいない**とき: 下の E1〜E4 のどれかを申告していれば警告 `evalNotChosen`
（エンジンは自分の既定で探す）。何も送らない。✓

| #   | 申告                                           | 送るもの                                                       | テスト |
| --- | ---------------------------------------------- | -------------------------------------------------------------- | ------ |
| E1  | `DNN_Model` / `DNN_Model1` …（数字だけが続く） | 最初の1つにファイル                                            | ✓      |
| E2  | `EvalFile`                                     | ファイル                                                       | ✓      |
| E3  | `EvalDir`                                      | フォルダ（ファイルを選んでいればその親、フォルダならそのまま） | ✓      |
| E4  | `Eval_Dir`                                     | 同上                                                           | ✓      |
| E5  | どれも無い                                     | 送らない。警告 `evalNotSupported`                              | ✓      |

E1 / E2 にフォルダを選んでいれば、送らずに警告 `evalNeedsFile`。✓ フォルダかどうかは起こす前に
ディスクを見る（上限2秒・取り消しに従う。読めなければファイル扱い——そのまま送れば、無いパスは
エンジンが読み込みの失敗として返す）。

## 定跡

**解析で使う**（`book.useInAnalysis`）:

| #   | 申告                                                            | 送るもの                                                                                                                                                                                                                                                                                                                                                                                                                                     | テスト |
| --- | --------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| B1  | `BookDir` と `BookFile`（combo）                                | ファイル名が選択肢にあれば `BookDir = 親` と `BookFile = 選択肢の綴り`（大小まで一致するものを先に、無ければ大小を無視して）。**無ければ、その回のプロセスにパスを受けるかを確かめる**（`setup::accepts_path_in`: 存在しないパスを送り、続く `usi` の `usiok` までに `combo value not found` が出るか）。受ければ `BookDir = 親` と `BookFile = パス`、受けなければ（上限 5 秒で答えなくても）送らずに定跡を切る（警告 `bookNameNotInVars`） | ✓      |
| B2  | `BookFile` / `Book_File`（string / filename）                   | パス                                                                                                                                                                                                                                                                                                                                                                                                                                         | ✓      |
| B3  | B1・B2 に当たらない（`BookDir` の無い combo、受ける名前が無い） | 送らずに定跡を切る。警告 `bookNotSupported`                                                                                                                                                                                                                                                                                                                                                                                                  | ✓      |
| B4  | `USI_OwnBook` / `OwnBook`                                       | **B1 / B2 で定跡を送れたときだけ** `true`                                                                                                                                                                                                                                                                                                                                                                                                    | ✓      |

**定跡を切る**（解析で使わない・定跡を選んでいない・B1 の外れ・B3）: B4 の名前 = `false`。`BookFile` /
`Book_File` が combo で選択肢に `no_book` があれば、**申告どおりの綴りで** `no_book`。✓
定跡を受ける名前があるのに切る口がどちらも無ければ、警告 `bookCannotBeDisabled`
（エンジンは自分の既定の定跡を使うことがある）。✓

**送れなかった定跡を切る理由**: `USI_OwnBook=true` だけを送ると、エンジンは自分の既定
（cwd からの `book/standard_book.db` など）で定跡を引く——利用者が選んでいない定跡で解析する。

## 固定値

呼び手の方針として `fixed` で受ける（解析は `ConsiderationMode = true`、`USI_Ponder = false`。
`analyzer.rs` の `analysis_fixed_values`）。**申告にあるときだけ送る。** ✓

## 送り方の規則

| #   | 規則                                                                                                                                                                                                                                                                                                                                                        | テスト |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| R1  | 送るもの = 利用者の値 ∪ 評価関数・定跡 ∪ 固定値。**同じ名前なら評価関数・定跡・固定値が勝つ**（警告 `overriddenByBinding`）。評価関数を受ける名前（E1〜E4 で当たった1つ）と定跡を受ける名前（`BookFile` / `Book_File` / `BookDir` / B4 の名前）の利用者の値は、評価関数・定跡を送らなかった回も送らない（`reserved_names`。画面はこの一覧を取得で受け取る） | ✓      |
| R2  | 申告に無い名前の利用者の値は送らない（警告 `notDeclared`。**画面には出さない**——既定で入る値を申告しないエンジンで起動のたびに出るため）                                                                                                                                                                                                                    | ✓      |
| R3  | 型の合わない値（`check` に真偽以外、`spin` に整数以外）は**送らずに警告** `invalidType`（送るとエンジンが落ちる。起動は断らない）。`check` の大小の揺れ（`True`）は受ける                                                                                                                                                                                   | ✓      |
| R4  | `spin` の範囲外 → 丸めて送る（警告 `clamped`）。`combo` の選択肢外 → 送らない（警告 `notInVars`）。`button` は送らない                                                                                                                                                                                                                                      | ✓      |
| R5  | 順: 利用者の値（**申告の順**）→ 評価関数 → 定跡 → 固定値                                                                                                                                                                                                                                                                                                    | ✓      |
| R6  | 名前は完全一致（大小を区別するエンジンがある）。例外は B1 のファイル名の照合                                                                                                                                                                                                                                                                                | —      |

警告は起動を止めない。画面は1枚のトーストで伝える（`EngineStartWarningBridge`）。
改行を含む・長すぎる値とパスは、起こす前に断る（`invalidValue`。`analyzer.rs` の `validate_input`）。✓

## 範囲外

- E3 / E4 でファイルを選んだとき、ファイル名は送らない（エンジンは自分の決めた名前を読む）
- 対局の起動（`start_game`）はこの段を通らない（`PlayerSpec.options` を並びのまま送る）
