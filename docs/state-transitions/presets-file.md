# 状態遷移表: プリセットのファイル（判定）

対象: `src-tauri/crates/settings/src/presets.rs`（`load_from` / `save_to`）と、
`src/entities/engine-presets/model/provider.tsx`（悲観更新）、
`src/app/providers/bridges/PresetsFileBridge.tsx`（利用者へ届ける）。

置き場は `app_config_dir/engine_presets.json`。画面の説明は
[settings.md](../spec/screens/settings.md) のエンジン管理が持つ。

**判定の出典は Rust**（`presets.rs`）。画面の `writable` は操作を出さないための写しで、
書けない状態の保存を断るのは `save_to`。

## 形と版

- v1: `{ "presets": [...] }`。版の欄が無い
- v2: `{ "version": 2, "presets": [...] }`。**欄の形は v1 と同じ**で、版の欄が付いただけ
- 1件（`EnginePreset`）で必須なのは `id` だけ。欠けた欄は既定値で読む。知らない欄は
  1件の中（`analysis` の中も）も最上位も持ち回る（`extra`）。値として持ち回るので、
  数の表記（`2.0` → `2`、64ビットに収まらない整数の丸め）と欄の順は保たない

**版を上げるとき**（欄の形を変えるとき）に触るのは、`CURRENT_VERSION`・`upgrade` に1段足すこと・
その段のテスト。古い版の原本は `engine_presets.v<元の版>.bak` に残る。

**古い版のアプリで開いた場合**:

- v1 の版は知らない欄を捨てて読むので、v2 のファイルは読める。**ただし読めない件を含む
  ファイルは読めない**（v1 の版は全欄必須でファイル全体を1回で読むので、1件の欠けで全件が
  読めない。読めなければ書かないので、失いはしない）
- v1 の版で保存すると `version` と知らない欄（`extra`）と読めない件が落ち、v1 に戻る。
  新しい版で開き直すと v1 として移し直す（`.bak` が1つ増える）。**この版が知っている欄は失わない**
- 新しい版（v3 以降）のファイルをこの版で開くと、形を問わず読み取り専用で開く（F4）

## 読み込み（判定順: `version` → 最上位の形 → 各件）

**版を形より先に見る。** 先の版が `presets` の形を変えたファイルを「壊れた」と読むと、退避して空から
始め、新しい版のデータをこの版で書き潰す。UTF-8 の BOM は読み飛ばす。

| 記号   | 状態           | 判定                                                                                                | 読み込み                                                                    | 書ける | 通知（`presetsLoadNoticeView`） | テスト |
| ------ | -------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ------ | ------------------------------- | ------ |
| **F0** | 無い           | ファイルが無い                                                                                      | 空で始める                                                                  | ○      | —                               | ✓      |
| **F4** | 新しい版       | `version` が 2 より大きい数（64ビットを超える数も）。`presets` の形は問わない                       | 読めた件を見せる（`presets` が配列でなければ0件）                           | ×      | `newerVersion`（warning）       | ✓      |
| **F3** | 壊れた         | JSON として読めない、最上位が object でない、`version` が数でない・負・小数、`presets` が配列でない | `engine_presets.unreadable-<時刻>.json` へ移してから空で始める              | ○      | `recovered`（warning）          | ✓      |
| F3x    | 壊れて移せない | F3 で rename が失敗                                                                                 | 空                                                                          | ×      | `notRecovered`（danger）        | ✗      |
| **F1** | 古い版         | `version` が無い・`null`・2 未満                                                                    | 原本を `.bak` へ → **書く直前に読み直し**、変わっていなければ v2 で書き戻す | ○      | `migrated`（info）              | ✓      |
| F1b    | 原本を残せない | F1 で `.bak` を書けない                                                                             | 移さずに読む                                                                | ×      | `backupFailed`（danger）        | ✗      |
| F1w    | 書き戻せない   | F1 で v2 を書けない、または移している間にファイルが変わった                                         | 読む                                                                        | ×      | `migrationFailed`（danger）     | ✗      |
| **F2** | 今の版         | `version == 2`（`2.0` も）                                                                          | 各件を読む                                                                  | ○      | —                               | ✓      |
| **F5** | 読めない       | 入出力エラー（EACCES / EIO）                                                                        | 空                                                                          | ×      | `unreadable`（danger）          | ✗      |

**読めない件**（F1 / F2 / F4 の中の1件。`id` が無い・欄の型が違う）: その件だけ除いて見せ、
保存のときに Rust が生の値を**末尾に**書き戻す。件数は `unreadableCount` で、通知は warning のトースト。

**`.bak`**: `engine_presets.v<元の版>.bak`。既に在って中身が同じなら書かない。違えば
`engine_presets.v<元の版>.bak-<時刻>`。

## 保存

保存は、読み込み（か直前の保存）で受け取った印（`revision`。中身のハッシュ）を渡す。
Rust は**書く直前にディスクを読み直し**、次の順で断る。読み直しから書くまでの間に他が書いた分は
見分けられない（ファイルの鍵は取らない）。

| 順  | 断る条件                                                                     | 種類       | 画面                                             |
| --- | ---------------------------------------------------------------------------- | ---------- | ------------------------------------------------ |
| 1   | `id` が空の件がある                                                          | `invalid`  | 帯                                               |
| 2   | ディスクを読めない（入出力）                                                 | `readOnly` | 帯「読み直す」                                   |
| 3   | 印が違う（読んだ後に他が書いた。新しい版・壊れたファイルに変わった回もここ） | `conflict` | 帯「読み直す」。編集中の入力は読み直すと元に戻る |
| 4   | 印は合うが、ディスクが今の版でない（F1b / F1w / F3x / F4 で開いた回）        | `readOnly` | 帯「読み直す」                                   |
| 5   | 書き込みに失敗                                                               | `io`       | 帯「設定を開く」                                 |

画面の側:

- **書けてから画面に反映する**（悲観更新）。断られたら画面は変えない。編集のダイアログは閉じず入力を残す
- **変更は1本ずつ通す**（`provider.tsx` の列）。次の一覧は最後に書けた一覧から組む——
  続けた変更の片方が消えることも、自分の変更どうしが `conflict` になることも無い
- 書けない状態（`writable` が偽）では変更の操作を出さず、押されても書かずに `readOnly`
- **0件で開いたら**、書ける状態のときだけ既定の1件を書いてから出す。書けなければ0件のまま、
  理由（`io` など）を帯で出す
- 読み込みの呼び出しそのものが失敗したら（`status === "error"`）、帯「読み直す」

## この表が満たすべき不変条件

1. **読めなかったファイルを上書きしない。** 上書きする前に退避する（F3）か、書かない（F1b / F1w / F3x / F4 / F5）
2. **知らない欄と読めない件を落とさない。** 1件の中（`analysis` の中も）の知らない欄、最上位の
   知らない欄、読めない件の生の値は、保存を通しても残る
3. **古い版の原本は完全な形で1つは残る**（`.bak` を書けなければ移さない。移していない古い版には
   `save_to` も書かない）
4. **別の書き手の変更を黙って上書きしない**（`revision`。移行の書き戻しも直前に読み直す）
5. **画面に出ている内容は、ディスクに書けた内容**（悲観更新）

## 埋まっていないセル

- F1b / F1w / F3x / F5: 書き込みや読み込みを失敗させる手段（権限を落とした一時ディレクトリ）を
  テストに持っていない。分岐はそれぞれ1箇所（`load_from` の `back_up_original` / 書き戻しの
  読み直しと `atomic_write` / `fs::rename` / `fs::read` の `Err`）で、書けない状態になることは
  コードで追えるが踏んでいない。F1b / F1w で開いた後の保存を `save_to` が断ることは、移していない
  v1 への保存（`an_unmigrated_file_is_never_overwritten`）で踏んでいる

テストは `presets.rs` の `tests`（Rust）、`engine-presets/model/__tests__/provider.test.tsx`
（悲観更新・列・書けない状態）、`app/providers/bridges/__tests__/presetsFileBridge.test.tsx`（通知）、
`src/__tests__/presetsWire.test.ts`（種類と欄の写し）。
