# 状態遷移表: プリセットのファイル（判定）

対象: `src-tauri/crates/settings/src/presets.rs`（`load_from` / `save_to`）と、
`src/entities/engine-presets/model/provider.tsx`（悲観更新）、
`src/app/providers/bridges/PresetsFileBridge.tsx`（利用者へ届ける）。

置き場は `app_config_dir/engine_presets.json`。画面の説明は
[settings.md](../spec/screens/settings.md) のエンジン管理が持つ。

## 形と版

- v1: `{ "presets": [...] }`。版の欄が無い
- v2: `{ "version": 2, "presets": [...] }`。**欄の形は v1 と同じ**で、版の欄が付いただけ
- 1件（`EnginePreset`）で必須なのは `id` だけ。欠けた欄は既定値で読む。知らない欄は
  1件の中も最上位も持ち回る（`extra`）

**古い版のアプリで開いた場合**: v1 の版は知らない欄を捨てて読むので v2 のファイルは読める。
保存すると `version` と知らない欄が落ちて v1 に戻り、新しい版で開き直すと v1 として移し直す
（`.bak` が1つ増えるだけ）。欄の形が同じなので、行き来で失うものは無い。**形を変える版
（v3）を足すときは、ここを設計し直すこと。**

## 読み込み（判定順: 最上位 → `version` → 各件）

| 記号   | 状態           | 判定                                                                        | 読み込み                                                       | 書ける | 通知（`PRESETS_LOAD_NOTICES`） | テスト |
| ------ | -------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------- | ------ | ------------------------------ | ------ |
| **F0** | 無い           | ファイルが無い                                                              | 空で始める                                                     | ○      | —                              | ✓      |
| **F1** | v1             | JSON が読め、`version` が無いか 2 未満                                      | 原本を `.bak` へ → v2 で書き戻す                               | ○      | `migrated`（info）             | ✓      |
| F1b    | 原本を残せない | F1 で `.bak` を書けない                                                     | 移さずに読む                                                   | ×      | `backupFailed`（danger）       | ✗      |
| F1w    | 書き戻せない   | F1 で v2 を書けない                                                         | 読む                                                           | ×      | `migrationFailed`（danger）    | ✗      |
| **F2** | v2             | `version == 2`                                                              | 各件を読む                                                     | ○      | —                              | ✓      |
| **F3** | 壊れた         | JSON として読めない、最上位が object でない、`version`/`presets` の型が違う | `engine_presets.unreadable-<時刻>.json` へ移してから空で始める | ○      | `recovered`（warning）         | ✓      |
| F3x    | 壊れて移せない | F3 で rename が失敗                                                         | 空                                                             | ×      | `notRecovered`（danger）       | ✗      |
| **F4** | 新しい版       | `version > 2`                                                               | 読めた件を見せる                                               | ×      | `newerVersion`（warning）      | ✓      |
| **F5** | 読めない       | 入出力エラー（EACCES / EIO）                                                | 空                                                             | ×      | `unreadable`（danger）         | ✗      |

**読めない件**（F1 / F2 / F4 の中の1件。`id` が無い・欄の型が違う）: その件だけ除いて見せ、
保存のときに Rust が生の値を**末尾に**書き戻す。件数は `unreadableCount` で、通知は warning のトースト。

**`.bak`**: `engine_presets.v1.bak`。既に在って中身が同じなら書かない。違えば
`engine_presets.v1.bak-<時刻>`。

## 保存

|                            | 書ける状態                            | 書けない状態（F1b / F1w / F3x / F4 / F5）  |
| -------------------------- | ------------------------------------- | ------------------------------------------ |
| 変更の操作                 | 書いてから画面に反映（悲観更新）      | 書かずに断る（`readOnly`）。操作を出さない |
| 読んだ後に他が書いていた   | 書かずに `conflict`。帯の「読み直す」 | —                                          |
| ディスクが新しい版・壊れた | 書かずに `readOnly`                   | —                                          |
| 書き込みの失敗             | `io`。画面は変えない                  | —                                          |
| 0件で開いた                | 既定の1件を書いてから出す             | 書かない                                   |

保存は、読み込み（か直前の保存）で受け取った印（`revision`。中身のハッシュ）を渡す。
Rust は**書く直前にディスクを読み直し**、印が違えば書かない。読み直しから書くまでの間に
他が書いた分は見分けられない（ファイルの鍵は取らない）。

## この表が満たすべき不変条件

1. **読めなかったファイルを上書きしない。** 上書きする前に退避する（F3）か、書かない（F1b / F1w / F3x / F4 / F5）
2. **知らない欄と読めない件を落とさない。** 1件の中の知らない欄、最上位の知らない欄、読めない件の生の値は、保存を通しても残る
3. **v1 の原本は完全な形で1つは残る**（`.bak` を書けなければ移さない）
4. **別の書き手の変更を黙って上書きしない**（`revision`）
5. **画面に出ている内容は、ディスクに書けた内容**（悲観更新）

## 埋まっていないセル

- F1b / F1w / F3x / F5: 書き込みや読み込みを失敗させる手段（権限を落とした一時ディレクトリ）を
  テストに持っていない。分岐はそれぞれ1箇所（`load_from` の `back_up_v1` / `atomic_write` /
  `fs::rename` / `fs::read` の `Err`）で、書けない状態になることはコードで追えるが踏んでいない

テストは `presets.rs` の `tests`（Rust）、`engine-presets/model/__tests__/provider.test.tsx`
（悲観更新・書けない状態）、`app/providers/bridges/__tests__/presetsFileBridge.test.tsx`（通知）、
`src/__tests__/presetsWire.test.ts`（種類の写し）。
