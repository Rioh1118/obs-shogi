# エンジン周りの横断の棚卸し（2026-11）

エンジン周りを Rust と TS をまたいだ1つの領域として見て、名前・境界・責務を判定した記録。
決めた構造は ADR-0015（`docs/decisions/0015-engine-target-structure.md`）が持つ。ここは根拠と行き先を持つ。

- 基点: `origin/main` の 20b74095
- 範囲: Rust は `src-tauri/src/engine/`（`commands/`、`game/` を含む）。TS は `src/entities/engine`、
  `src/entities/engine-presets`、`src/entities/analysis`、`src/entities/game-session`、`src/features/engine-position-sync`、
  `src/features/settings` のエンジンタブとプリセット編集、`src/widgets/analysis-pane`、`src/app/providers/bridges` のエンジンに関わるもの
- 書かないもの: 行番号（`docsSourcePaths` の `lineNumberRefsIn` が止める）。場所はパスと識別子で書く

## 手順

1. 棚卸しは `/cross-cutting-audit` の `inventory.mjs` で機械に作らせ、範囲のパスで絞った。
   関数 298、型 188、Tauri コマンドと呼び出し 42、エラー 17、文言 311 行。
   綴りを揃えて同じになる名前の組は 66 組（Rust と TS をまたぐ 45、Rust の中 18、TS の中 3）
2. 範囲の中のルール違反は、範囲で割った3本（Rust の `game/` 以外、Rust の `game/` と `commands/game.rs`、TS）が判定した。
   確信度80未満と好みの問題は落としてある
3. 範囲をまたぐもの（同名の組、線の対応、スライスの向き、語）はメインが本体を開いて判定した

## 同名の組の判定

Rust と TS をまたぐ 45 組のうち 44 組は、TS の `rust-types.ts` か `api/tauri.ts` が Rust の型とコマンドを
同じ綴りで写すもの（`GameEvent`、`StartOutcome`、`ProbeOutcome`、`GameSnapshot`、`start_game` など）で、**対応表**。
残る1組が下の C-1。

Rust の中の 18 組のうち、`GameManager` と `GameSession` の同名のメソッド（`start` `submit_move` `continue_game`
`end_by_rule` `resign` `abort` `close` `snapshot`）は、台帳が ID で引いて転送するだけで判断を持たないことを本体で確かめた。
`registry::spawn` と `child::spawn`、`registry::shutdown` と `analyzer::shutdown`、`protocol::end_watch` と `analyzer::end_watch`、
`analyzer::set_position` とコマンドの `set_position` は、段違いに同じ概念を持ち、上が検査を足して下へ渡す形。
`new` `get` `view` は型ごとの慣用。どれも直さない。TS の中の3組のうち `reducer` はスライスごとの慣用、
`PresetFieldErrors` と `presetFieldErrors` は型とその組み立ての関数。
