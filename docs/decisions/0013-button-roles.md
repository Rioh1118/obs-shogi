# ADR-0013: 主ボタンを確定と次の一手に分ける

- 状態: 採用
- 日付: 2026-11-01
- 決めたもの: 利用者（見本 A〜D から D を選択）
- 関連: ADR-0005（決定1の `tone` の表と決定2の主ボタンの面を置き換える）

## 文脈と問題

全部の主ボタンが同じ茶の面に白文字で、1画面に強いボタンが複数並び、利用者は「浮いている」と判定した。

## 判断の基準

1. 利用者の明示した言葉（見本を見て決める）
2. R-DEC-1: 文字の比を基準以上に保つ
3. R-DEC-2: 額縁に新しい色を足さない

## 検討した選択肢

- A 全部砂色 / B 全部銅の枠 / C 濃い茶に砂色の文字 / D 役割で分ける

## 決定

D を選ぶ。`primary` は確定で、砂色の面に暗い文字（`$color-commit-solid`）。1画面に1つ。
`accent` は次の一手で、銅の枠と文字（`$color-accent-text`）。ホバーは枠を明るくし、面を敷かない。

### 結果

- 砂色は文字と同じ素材、銅は印なので、額縁の色は増えない
- 呼び出し側が役割を選ぶ。`1画面に1つ` は機械で止めていない

### 失効条件

利用者が確定の面をやめると判定したとき。
