# 機能要件: 評価関数フォルダ（`eval_options.txt` と評価関数の型）

追跡: #747（エピック） #743 #744
main にあるか: **評価関数の型はある**（#744。読むのは `engine/eval_arch.rs`、欄に出すのは `evalTypeOf`、失敗の種類は `evalTypeMismatch`）。**`eval_options.txt` は無い**（#743）

**一文の目的。** やねうら王系の配布物（評価関数と、その推奨設定を書いた `eval_options.txt`）を
AI ライブラリに置いたとき、エンジンが実際に使う設定と、画面に出る設定を食い違わせない。

**事実:** `research/engines/yaneuraou-files.md`（2026-11-21 に V9.90 開発版と V9.00Git で実測）

## いまどうなっているか

| できること                                               | できないこと                                                                                           |
| -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `<AI 名>/eval/` のファイルを評価関数の候補に並べる       | `eval_options.txt` を知らない。中身を読まず、`nn.bin` と並べて**評価関数の候補に出す**               |
| `FV_SCALE` などを他のオプションと同じ欄で編集して送る    | エンジンは `isready` で `eval_options.txt` を読み、**送った値を上書きする**。画面の値は効いていない    |

**食い違いは黙って起きる。** 上書きは `info string` の1行だけで、エラーにならない。
`eval_options.txt` を `eval/` の外（`<AI 名>/` の直下）に置くと読まれず、
`FV_SCALE` は既定の 16 のまま動く（推奨が 24 や 40 の評価関数がある）。

## 受入条件

### `eval_options.txt`

- **AC-E1** AI ライブラリは `<AI 名>/eval/eval_options.txt` を見つけ、`<名前> <値>` の行を読む。
  評価関数の候補には出さない
- **AC-E2** プリセット編集で、そのフォルダの評価関数を選ぶと、`eval_options.txt` が決めるオプションの欄は
  ファイルの値を出し、編集できない。欄の横に「評価関数フォルダの `eval_options.txt` が決める」と出す。
  プリセットに保存済みの値は消さない
- **AC-E3** `<AI 名>/` の直下に `eval_options.txt` があり `eval/` に無いとき、AI ライブラリの診断に
  「`eval/` の中に置かないと読まれない」と出す
- **AC-E4** AI ライブラリの手順（ファイルを置く段）が、`eval_options.txt` を `eval/` に置くことを書いている

AC-E1〜AC-E4 → #743

### 評価関数の型

- **AC-E5** プリセット編集の評価関数の欄に、選んだファイルの先頭から読んだ型（`HalfKA2` / `HalfKP` と
  入力の幅）を出す。読めないファイルには何も出さない（エラーにしない）
- **AC-E6** 起動が `FileMissMatch` で失敗したら、帯は「評価関数の型がこのエンジンと合わない」と言い、
  評価関数の型を添え、「同じ型の実行ファイルを選ぶ」で終える。エンジンの出力は今どおり添える

AC-E5 AC-E6 → #744

## 判断ログ

| 判断                                       | 選択                                       | 理由と基準                                                                                                  | 戻し方                                   |
| ------------------------------------------ | ------------------------------------------ | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| `eval_options.txt` が決める欄をどうするか  | ファイルの値を出し、編集させない           | 編集できると、効かない値を保存できてしまう。エンジンは必ず上書きする（実測）                                  | 欄を開け、送る値の上書きを警告に変える   |
| 型の不一致を起動の前に止めるか             | 止めない。型を見せ、失敗の文で言い当てる   | エンジンは自分の型を申告しない（`id name` に型が無い）。実行ファイルの名前から推すと、名前を変えたら外れる | 型を申告するエンジンが出たら前で止める   |
| 実行ファイルの隣の `engine_options.txt`    | 扱わない                                   | AI ライブラリの置き場の外。手元の配布物に入っていない                                                      | 配布物に入ったら AC-E2 と同じ形で足す    |
