# 機能要件: 局面編集モード

追跡: #113（親は #289）
main にあるか: **無い**

## なぜ要るか

**任意局面から研究を始める入口が無い。** いまできるのは3つだけ。

| いまできること         | 限界                                               |
| ---------------------- | -------------------------------------------------- |
| 手合割から新規作成     | 13種類のプリセットしか選べない                     |
| 課題局面から棋譜を作成 | その SFEN が既に課題局面に登録されている必要がある |
| 棋譜をインポート       | 棋譜テキストを持っている必要がある                 |

つまり「本で見た局面を並べて調べる」ができない。
issue #113 はこれを「SFEN 貼り付け頼み」と書いている。

## 受入条件（#113）

- 局面編集モードの開始／終了
- 盤上・駒台への任意配置（ドラッグ＆ドロップ）
- 手番の変更
- 駒落ちプリセットの投入（香落ち〜十枚落ち、詰将棋）／駒の増減
- 編集結果から新規棋譜を作成できる

## 触ることになる画面

| 画面                                      | 何が変わるか                                         |
| ----------------------------------------- | ---------------------------------------------------- |
| [盤](../screens/board.md)                 | クリックの意味が「指す」から「置く／取る／裏返す」へ |
| [ファイル作成](../screens/create-file.md) | 初期局面の決め方に「編集した局面」が増える           |
| [課題局面](../screens/study-positions.md) | 編集した局面をそのまま登録できるようにする           |

## 決まっていないこと

- **モードをどこで切り替えるか。** ヘッダ・解析ペイン・盤の上のどこにも
  余っている場所が無い
- **編集中に棋譜をどう扱うか。** 開いている棋譜の初期局面を書き換えるのか、
  別の新しい棋譜になるのか。前者は既存の手をすべて捨てることになる
- **入玉・詰将棋の局面で合法性をどこまで見るか。** 玉が2枚ある・
  二歩になっている局面を作れてしまうと、そこから指した手が壊れる

## 先に片付けるべきもの

**#276（棋譜の編集が黙って失われる）が先。**
#289 が明記している通り、局面編集は棋譜を書き換えるので、
保存経路が直る前に着手すると「編集したのに消える」経路を増やすことになる。

関連して次も効く。

- #262 開いている棋譜をリネーム／移動すると編集が巻き戻る
- #210 UTF-8 / Shift_JIS 以外の棋譜が「0手」として開き、1手指すと元ファイルを上書きする
