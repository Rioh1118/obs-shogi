# 機能要件: 特殊な手の挿入

追跡: #115（親は #289）
main にあるか: **読める。書けない**

## いまどうなっているか

### 読める

`JKFSpecial`（`src/entities/kifu/model/jkf.ts`）は**8つ**を持つ。

| 定数         | 意味                 |
| ------------ | -------------------- |
| `TORYO`      | 投了                 |
| `JISHOGI`    | 持将棋               |
| `SENNICHITE` | 千日手               |
| `TSUMI`      | 詰み                 |
| `FUZUMI`     | 不詰                 |
| `TIME_UP`    | 時間切れ             |
| `CHUDAN`     | 中断                 |
| `KACHI`      | 入玉勝ち（宣言勝ち） |

これらは棋譜ストリームの行に**指し手と同じ欄で**出る
（`readableMove` が `move` と `special` の両方を扱う）。
分岐の候補一覧にも同じ集合で入る。

Rust 側も同じように扱う。索引は `special` を見たらその系列を終端として扱い
（`position_apply.rs`）、局面を動かさないノードとして飛ばす（`position_key.rs`）。

### 書けない

**挿入する経路が1つも無い。** 盤で指せるのは合法手だけで、
棋譜ストリームのメニューにあるのは「削除」「入れ替え」だけ。

## 受入条件（#115）

- 中断／投了／引き分け／持将棋／千日手／詰み／不詰
- 時間切れ／反則勝ち／反則負け／入玉勝ち 等
- 棋譜末端への特殊手の挿入と、**各形式（KIF / CSA / JKF）への出力整合**

**受入条件の一覧は `JKFSpecial` の8つより広い。**
反則勝ち・反則負けは `JKFSpecial` に無いので、
どう表すか（`OTHER` 的な逃がしを作るか、定数を増やすか）は決まっていない。

## 出力の整合が本体

**この issue の重さは UI ではなく変換にある。**

同じ `special` が KIF / KI2 / CSA / JKF で別の綴りになり、
形式によっては表せないものがある。`normalize_jkf` と `convert_jkf_to_format`
（Tauri コマンド）を通る往復で落ちないことを確かめる必要がある。

**いまその往復を見ているテストは無い。** `docs/OPEN-QUESTIONS.md` Q-004 が
「棋譜変換の golden round-trip テストは2〜3時間の作業」として置いてある問い。
**特殊手を書けるようにする前に、この往復のオラクルを先に作るべき。**

Rust 側の `kifu_reader.rs` には
「クレートが `special` にしない終局理由（`%TIME_UP` など）もここで止まる」という
注記がある。**読み取りの側でも全部が `special` になるわけではない。**

## 対局との関係

対局が入ると、終局の理由（`GameOverReason`）を棋譜の `special` に落とす経路が要る。

| `GameOverReason` | 対応する `special`                          |
| ---------------- | ------------------------------------------- |
| `Resign`         | `TORYO`                                     |
| `DeclareWin`     | `KACHI`                                     |
| `Timeout`        | `TIME_UP`                                   |
| `Rule`           | `TSUMI` / `SENNICHITE` / `JISHOGI` のどれか |
| `Aborted`        | `CHUDAN`                                    |
| `EngineFailure`  | **対応が無い**                              |

最後の1行が決まっていない。→ [game-play.md](game-play.md)
