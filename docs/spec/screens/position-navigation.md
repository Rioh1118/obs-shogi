# 画面仕様: 局面ナビゲーション

対象: `src/features/position-navigation/`
`modal=navigation`

## 目的

**盤を動かさずに、分岐を辿って行き先を決める。**
決めてから Enter で一度だけ盤を移す。棋譜ストリームが「一覧から選ぶ」のに対し、
こちらは「1手ずつ進めながら候補を見る」。

## 出入口

| 入口            | 出口                               |
| --------------- | ---------------------------------- |
| 解析ペインの 🧭 | Enter → `applyCursor` して閉じる   |
|                 | Esc・オーバーレイ → 何もせず閉じる |

開いたときの位置は**盤の現在位置**。閉じている間は何も計算しない。

## 画面構成

```
┌─────────────────────────────────────────────────────┐
│ 局面ナビゲーション        [手番/手数などの状況]      │
├──────────────────────┬──────────────────────────────┤
│                      │  ▶ ▲２六歩        （本譜）   │
│   盤のプレビュー      │    ▲７八金        （変化1） │
│                      │    ▲６八玉        （変化2） │
├──────────────────────┴──────────────────────────────┤
│ [h/l] 手順移動  [j/k] 分岐選択  [Enter] 確定  [Esc] │
└─────────────────────────────────────────────────────┘
```

**このモーダルだけ `theme="light"`。** 他はすべて暗い面に載る。
中の分岐カードが明るい面を前提に組んであり、揃えるには作り直しが要る → #183

## 状態

`nav` は2つの値しか持たない。

| 値                    | 意味                         |
| --------------------- | ---------------------------- |
| `previewCursor`       | いまプレビューしている位置   |
| `selectedOptionIndex` | 候補一覧のうち選んでいる番号 |

| 記号 | 状態         | 判定                   | 右側に出るもの                              |
| ---- | ------------ | ---------------------- | ------------------------------------------- |
| V0   | 候補あり     | 通常                   | `BranchList`                                |
| V1   | 終端         | `options.length === 0` | 空の候補一覧                                |
| V2   | 再現できない | `unreachable`          | 「この棋譜は N 手目を盤上で再現できません」 |

`V2` は、盤上で再生できない手を含む棋譜（正規化に失敗したまま開いたもの）で
`buildPlayer` が投げたときに立つ。**Enter も止める。**
判定を1箇所に置いているので、「再現できません」と出ているのに Enter だけ通る、
という食い違いは起きない。

## 操作と結果

| キー           | 結果                                    |
| -------------- | --------------------------------------- |
| `l` / `→`      | 選んでいる候補へ1手進む                 |
| `h` / `←`      | 1手戻る（`tesuu` を1減らす）            |
| `j` / `↓`      | 候補を下へ                              |
| `k` / `↑`      | 候補を上へ                              |
| `Enter`        | `applyCursor(previewCursor)` して閉じる |
| `Esc`          | 何もせず閉じる（`Modal` が受ける）      |
| 候補をクリック | その候補を選ぶ（進みはしない）          |

キーは `window` の `keydown` で拾い、**扱った鍵だけ `preventDefault` する**。
無条件に止めると Tab の既定動作まで消え、`Modal` の閉じ込めが効かなくなる。
Escape はここでは拾わない（受け口を2つ持たないため）。

## 失敗の見せ方

| 失敗                         | どこに出るか                              |
| ---------------------------- | ----------------------------------------- |
| プレビューが辿れない         | 右側に「N 手目を盤上で再現できません」    |
| `applyCursor` が着けなかった | **出ない。** モーダルは閉じ、盤は動かない |

後者は `entities/game` が `catch` して `state.error` に積むだけで終わる。→ #277

## いま満たしていないこと

- **明るい面に載る唯一のモーダル** → #183
- **`h` は `tesuu` を1減らすだけ** で、分岐の選択（`forkPointers`）は残る。
  戻ってから別の分岐へ入り直すと、その先の計画が残っている場合がある
- **確定できなかったことが画面に出ない**（上記）
- **局面検索・局面ナビの非同期と effect にまとまった問題がある** → #288
