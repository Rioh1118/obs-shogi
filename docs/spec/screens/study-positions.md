# 画面仕様: 課題局面

対象: `src/features/study-positions-manager/`（一覧）
`src/features/study-position-save/`（登録・編集）
`src/entities/study-positions/` `src-tauri/src/settings/`

`modal=study-positions` / `modal=study-position-save`

状態遷移: **未作成**（`docs/state-transitions/README.md` が `study-positions.md` を
未作成として挙げている）。この画面の状態は下の表が暫定で持つ。

## 目的

**「あとで調べたい局面」を SFEN で溜め、状態とタグで整理する。**
棋譜のどこかではなく**局面そのもの**に紐づくので、棋譜をまたいで同じ局面を1つに扱える。

## データ

`StudyPosition` は棋譜ファイルではなく **アプリの設定ディレクトリ**に置かれる
（`load_study_positions` / `save_study_positions`）。棋譜ファイルは書き換えない。

| 欄                        | 内容                                      |
| ------------------------- | ----------------------------------------- |
| `id`                      | 採番した識別子                            |
| `sfen`                    | 局面。**同一性の鍵**（`findBySfen`）      |
| `label`                   | タイトル                                  |
| `description`             | メモ                                      |
| `state`                   | `inbox` / `active` / `reference` / `done` |
| `tags`                    | 文字列の配列                              |
| `createdAt` / `updatedAt` | ISO 文字列                                |

状態の日本語は `未整理` / `研究中` / `資料` / `完了`。

## 出入口

```
ヘッダの📚 ──→ study-positions（一覧）
                 ├[検索] or s ──→ position-search?sfen=…&returnTo=study-positions
                 ├[編集]  or e ──→ study-position-save?sfen=…&returnTo=study-positions
                 └[棋譜作成] ───→ sfen-kifu-create?sfen=…&returnTo=study-positions

解析ペインの🔖 ──→ study-position-save（現在局面。returnTo なし）
```

しおりアイコンは、現在局面が登録済みなら**塗りつぶして**「編集」になる。

## 一覧（`study-positions`）

### 画面構成

```
┌ 課題局面 ───────────────────────────────────────────────┐
│ [全て 12][未整理 3][研究中 5][資料 2][完了 2]           │
│ ─────────────────────────────────────────                │
│ [🔍 ラベル・メモを検索      ][⚙ タグ]                   │
│ タグチップ（選択中）                                     │
│ [更新日↓ ▾]                        8件 / 12件中         │
│ ┌──────────────────┐  ┌──────────────────────────────┐  │
│ │ 局面リスト        │  │ 詳細                          │  │
│ │ ▸ 角換わり…       │  │  盤プレビュー                 │  │
│ │   45角…           │  │  タイトル / 状態 / タグ / メモ│  │
│ │                   │  │  [編集][棋譜作成][検索]       │  │
│ └──────────────────┘  └──────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 絞り込みの順序

**この順で通す。** タグの候補が「いま見えている範囲」から出るようにするため。

1. 状態タブ
2. 本文検索（ラベル・メモ・タグを対象）
3. **ここまでの結果からタグ候補を数える**（上位8件）
4. タグの絞り込み（**AND**）
5. 並べ替え（更新日↓↑ / 作成日↓ / ラベル順）

タグパネルは「いまの候補」と「全体でよく使うタグ」の2列を出す。

### 状態

| 記号 | 状態          | 判定                                | 出るもの                   |
| ---- | ------------- | ----------------------------------- | -------------------------- |
| S0   | 1件も無い     | `positions.length === 0`            | 「★ ボタンで登録できます」 |
| S1   | 絞り込みで0件 | 全体はあるが `displayPositions` が0 | 「条件をクリア」ボタン     |
| S2   | 一覧          | 上記以外                            | 行＋詳細                   |

**選択は必ず1つある**（一覧が空でなければ）。表示中の一覧から消えた場合は
先頭へ寄せ直す。

### 操作と結果

| 操作            | 結果                                                   |
| --------------- | ------------------------------------------------------ |
| `↓` / `j`       | 次の局面（**入力欄にいる間は効かない**）               |
| `↑` / `k`       | 前の局面                                               |
| `s`             | その局面で局面検索を開く                               |
| `e`             | その局面の編集を開く                                   |
| `Esc`（検索欄） | 検索語を消す。**消すものが無いときはモーダルを閉じる** |
| 行をクリック    | 選択                                                   |

選択が動くと一覧はスムーススクロールで追う（上下15%/85%の外に出たときだけ）。

**子のモーダルを開いている間、絞り込みの state は捨てない。**
`returnTo=study-positions` が URL にある間は「一時的に隠れているだけ」と見なす。

## 登録・編集（`study-position-save`）

### 画面構成

左に盤のプレビューと文脈（手番／手数／ファイル名）、右に入力欄4つ。

| 欄       | 種類                     |
| -------- | ------------------------ |
| タイトル | 1行                      |
| 研究状態 | 4つから1つ（セグメント） |
| タグ     | `TagsInput`              |
| メモ     | 複数行                   |

手数とファイル名は **`sfen=` で来たときは出さない**。
その場合の「現在の棋譜の手数」は別の棋譜のものになるため。

### 状態

| 記号 | 状態       | 判定                      | 変わるもの                                   |
| ---- | ---------- | ------------------------- | -------------------------------------------- |
| E0   | 新規登録   | `findBySfen(sfen)` が無い | 見出し「課題局面に登録」／ボタン「登録する」 |
| E1   | 編集       | 見つかった                | 見出し「課題局面を編集」／「削除」が出る     |
| E2   | 保存中     | `isSaving`                | 全欄が無効                                   |
| E3   | 削除の確認 | `confirmDelete`           | `ConfirmDialog`                              |

**同一性は SFEN。** 同じ局面をもう一度登録しようとすると編集になる。

### 操作と結果

| 操作                       | 結果                                |
| -------------------------- | ----------------------------------- |
| `⌘/Ctrl + Enter`           | 保存                                |
| 「登録する」／「保存する」 | 保存して閉じる（`returnTo` を辿る） |
| 「削除」                   | 確認 → 削除して閉じる               |
| 「キャンセル」             | 閉じる                              |

## 失敗の見せ方

| 失敗             | どこに出るか                                                       |
| ---------------- | ------------------------------------------------------------------ |
| 登録・編集の保存 | フォームの下に赤字（`errorMsg`）                                   |
| 削除             | 同上                                                               |
| 一覧の読み込み   | **出ない**（`entities/study-positions` の `error` に読み手が無い） |

一覧側の削除（詳細パネルの削除）も、失敗を出す場所を持っていない。

## いま満たしていないこと

- **一覧の読み込み失敗が出ない**（`study-positions` の `error` は2箇所で立つが読み手0）
  → ADR-0004 の実測表
- **状態遷移表が無い**（`docs/state-transitions/README.md` が未作成として挙げている）
- **タグの候補が上位8件で切られている。** それを超える分は入力で探すしかなく、
  画面には「他にもある」と出ない
- **登録した局面が棋譜のどこに出てくるかは、検索を開くまで分からない**

## これからの要件

- 課題局面と**棋譜内のしおり**（#118）は別物。後者は注釈機能の設計が決まるまで着手しない
  （`docs/IDEAS.md`）
- 局面編集モードが入ると「盤で組んだ局面をそのまま登録する」経路ができる
  → [features/position-edit.md](../features/position-edit.md)
