# 画面仕様: エンジンプリセットの編集

対象: `src/features/settings/ui/engine-preset-dialog/`
`src/entities/engine-presets/`
URL を持たない（設定の「エンジン管理」タブの上に重なる別窓）

## 目的

**1つのエンジンを「どう起動して、どう読ませるか」を1枚にまとめる。**
エンジン本体・評価関数・定跡・USI オプション・解析の既定値が1つのプリセットになる。

## 出入口

エンジン管理タブのカードの「編集」で開く。閉じるのは「保存」か「キャンセル」か Esc。

**URL に乗らない**ので、リロードすると閉じる。
編集中の内容は下書き（`draft`）にしか無いので、閉じると消える。

編集中にそのプリセットが消えたら、自動で閉じる。

## 画面構成

4つの節を縦に並べる。

| 節                 | 中身                                                   |
| ------------------ | ------------------------------------------------------ |
| 基本               | 名前 / AI プロファイル（`ai_root` 直下のディレクトリ） |
| エンジンとファイル | エンジン本体 / 評価関数 / 定跡の有無と定跡ファイル     |
| 重要なオプション   | MultiPV / Threads / USI_Hash                           |
| 解析の既定値       | 時間 / 深さ / ノード / 詰み探索                        |

### 候補の集め方

開いたとき `scanAiRoot(ai_root)` を1回走らせ、その結果から候補を作る。
`ai_root` が未設定なら候補は空になり、節の中から選び直せる。

| 選択肢          | 元                                                       |
| --------------- | -------------------------------------------------------- |
| AI プロファイル | `index.profiles`                                         |
| エンジン        | `index.engines` のうち **`YaneuraOu_` で始まるものだけ** |
| 評価関数        | 選んだプロファイルの `eval/`（`nn.bin` を先頭へ寄せる）  |
| 定跡            | 同じプロファイルの `book/` の `.db`                      |

エンジンには「AI ラベルでの絞り込み」が付く。**この絞り込みは保存しない**（画面だけの値）。
絞り込みの外にある現在の選択は、候補の先頭に「（現在の選択）」として残す。
落とすと選択が消えて画面が壊れる。

### 空欄だけの自動補完

候補が揃った時点で、**空の欄だけ**を埋める。

1. AI プロファイルが空 → `eval` を持つ最初のプロファイル
2. エンジンが空 → 絞り込み後の最初のエンジン
3. 評価関数が空 → `nn.bin`、無ければ最初のファイル
4. 定跡を有効にしていて定跡が空 → 最初の `.db`

**すでに入っている値は上書きしない。**

### 数値の3欄

| 項目     | 取りうる値                           | 「自動」の意味   |
| -------- | ------------------------------------ | ---------------- |
| MultiPV  | 1〜`MULTIPV_MAX`。よく使う値はボタン | —（自動は無い）  |
| Threads  | 1〜論理コア数                        | `min(コア数, 8)` |
| USI_Hash | 128〜65536 MB                        | 既定値 1024 MB   |

「自動／手動」は**保存する値ではない**。開いたときに
「いまの値が推奨値と一致するか」で決め直す。

## 状態

| 記号 | 状態           | 判定                        | 出るもの                        |
| ---- | -------------- | --------------------------- | ------------------------------- |
| G0   | 閉             | `open === false`            | 何も描かない（Hook も走らない） |
| G1   | スキャン中     | `indexStatus === "loading"` | 候補が空のまま                  |
| G2   | スキャン失敗   | `indexStatus === "error"`   | `AI_ROOT のスキャンに失敗…`     |
| G3   | 編集中         | `indexStatus === "ok"`      | 候補が入った状態                |
| G4   | 入力の誤りあり | `errors` が空でない         | 欄ごとに赤字                    |

`open === false` のときは Hook を1つも呼ばない
（`EnginePresetEditDialogPanel` が Hook 無しのラッパになっている）。

## 操作と結果

| 操作                | 結果                                         |
| ------------------- | -------------------------------------------- |
| 「保存」            | 検証 → `updatePreset` → 閉じる               |
| 「キャンセル」／Esc | 下書きを捨てて閉じる                         |
| 「再スキャン」      | `scanAiRoot` をやり直す                      |
| 「AI ルートを選ぶ」 | フォルダ選択。**失敗したら AI 名の欄に出す** |
| 「engines/ を作成」 | `ensureEnginesDir` → 再スキャン              |

### 保存時の検証

| 欄           | 条件                       | 文言                                   |
| ------------ | -------------------------- | -------------------------------------- |
| 名前         | 空でない                   | 名前は必須です                         |
| AI 名        | 空でない                   | AI名（プロファイル）を選択してください |
| エンジン     | 空でない                   | エンジンを選択してください             |
| 評価関数     | 空でない                   | 評価関数ファイルを選択してください     |
| 定跡ファイル | 定跡を有効にしたら空でない | 定跡ファイルを選択してください         |

保存時の整形:

- 解析の既定値は **0 以下を落とす**。時間 0〜3600 / 深さ 0〜999 / ノード 0〜999,999,999
- 4つとも空なら `analysis` 自体を持たせない
- USI オプションの**空文字は保存しない**
- MultiPV / Threads / USI_Hash は画面の値で上書きする
- 最後に `{ ...DEFAULT_USI_OPTIONS, ...options }` で既定値を敷く

保存が通ると、必要ならエンジンが再起動される。

## 失敗の見せ方

| 失敗                 | どこに出るか              |
| -------------------- | ------------------------- |
| `ai_root` のスキャン | 基本の節（`indexError`）  |
| `engines/` の作成    | 同上                      |
| AI ルートの選び直し  | AI 名の欄                 |
| 入力の誤り           | 欄ごと                    |
| **保存そのもの**     | **出ない。** 閉じてしまう |

最後の1つが #170。`updatePreset` は楽観的に画面を更新するので、
ディスクへの書き込みが落ちても画面は保存済みのままになる。

## いま満たしていないこと

- **保存の失敗が出ない**（上記）→ #170
- **編集できる USI オプションが3つだけ**。エンジンが申告する `option` 行を
  読んで欄を作る仕組みが無い → #83
- **エンジンの候補が `YaneuraOu_` で始まる名前に絞られている。**
  他のエンジンは一覧に出ない
- **定跡の候補が `.db` だけ** → #84
- **解析の既定値を入力できるのに、解析の実行へ届いていない** → #107 #110
- **URL を持たないのでリロードで消える**
