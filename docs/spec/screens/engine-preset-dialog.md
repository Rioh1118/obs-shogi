# 画面仕様: エンジンプリセットの編集

対象: `src/features/settings/ui/engine-preset-dialog/`
`src/entities/engine-presets/`
URL を持たない（設定の「エンジン管理」タブの上に重なる別窓）

## 目的

**1つのエンジンを「何で動かし、どう解析し、どう設定するか」を1枚にまとめる。**

## 出入口

エンジン管理タブのカードの「編集」で開く。閉じるのは「保存」か「キャンセル」か Esc。

**URL に乗らない**ので、リロードすると閉じる。
編集中の内容は下書きにしか無いので、閉じると消える。

編集中にそのプリセットが消えたら、自動で閉じる。

## 画面構成

上から、名前と3つの節。**同じ設定を2か所で書かない。**

| 節             | 中身                                                                           |
| -------------- | ------------------------------------------------------------------------------ |
| 名前           | プリセットの名前                                                               |
| 使うもの       | エンジン / 評価関数 / 定跡（`UsedFilesSection`）                               |
| 解析           | 候補手の数 / 止める条件（時間・深さ・ノード数）/ 詰み探索（`AnalysisSection`） |
| エンジンの設定 | エンジンが申告したオプションの1つのリスト（`EngineSettingsSection`）           |

**AI のフォルダ（`ai_root`）はこの画面では選ばない。** 設定の「AI ライブラリ」で選ぶ。
未設定なら「使うもの」にそう出す。

### 使うもの

開いたとき `scanAiRoot(ai_root)` を1回走らせ、その結果から候補を作る。エンジンの欄の「探し直す」で
やり直せる（**いつも押せる**——探すのが返らない環境（応答しないドライブ）と、開いたままエンジンを置いた
ときに、閉じずに探し直す口が要る）。

| 欄       | 選択肢                                                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| エンジン | `index.engines` の全部。**名前で絞らない**（列挙は engines/ の直下と1段下のフォルダの実行ファイル）。`presetEngineOptions`。読み込めたエンジンは**名乗り（`id name`）**で出す                                  |
| 評価関数 | 「指定しない」と、AI ライブラリの全部のフォルダの `eval/` を「フォルダ / ファイル」で（`evalChoices`。フォルダごとに `nn.bin` を先に）。選んだフォルダがプリセットの `aiName` になり、「指定しない」で空になる |
| 定跡     | 「使わない」と、全部のフォルダの `book/` の `.db` を「フォルダ / ファイル」で（`bookChoices`）。**選んだ定跡は解析で使い、定跡ビューにも出す**。「使わない」ならどちらにも出ない（`bookInUse`）                |

選択肢に無い保存済みのパス（消えた・手で書いた）は「（現在の選択）」として「指定しない」「使わない」の次に残す。
エンジンの欄の下には、選んだエンジンのパスを小さく出す（名乗りだけでは同じ名前の別のビルドを見分けられない）。

起動できない見込みのエンジンも**外さずに**、名前の後ろに理由を添える。

| 見込み（`launchability`） | 添える理由                           | 選べるか |
| ------------------------- | ------------------------------------ | -------- |
| `ready`                   | —                                    | 選べる   |
| `notExecutable`           | 実行権限がありません                 | 選べる   |
| `quarantined`             | macOS がまだ開くのを許可していません | 選べる   |
| `unreadable`              | 読めません                           | 選べない |
| `wrongPlatform`           | 別の OS 向けです                     | 選べない |

### エンジンの読み込み

**エンジンを選べば裏で読み込む。開いたときも1回読み込む**（エンジンを起こして申告（名前・オプションの定義）
だけを取り、すぐ落とす。`probe_engine`）。`usi` の往復だけなので軽い。

- **うまくいけば何も言わない。** 欄の下に出すのは読み込み中（「エンジンを読み込んでいます…」と「やめる」）と、
  読めなかったとき（理由・次にすること・「もう一度読み込む」。OS・エンジンの出力があれば「詳細」）と、
  いまのエンジンを読み込めないまま止まっているとき（「やめる」の後など。「まだ読み込んでいません」と
  「もう一度読み込む」）だけ（`probeStatusText`）。失敗は、失敗したパスがいまのパスのときだけ。
  **止まった形を黙らせない**——同じエンジンは選び直しても読み込まれないので、読み込み直す口が消える
- 名乗り（`id name`）は、いまのエンジンを読み込めたときだけ使う。エンジンを選び直したら消す
- 読み込み中は保存できない。「やめる」で保存でき、後から返った結果は使わない
- 最後に撃った読み込みの結果だけを使う（`presetDialogReducer`。判定表 `docs/state-transitions/engine-preset-dialog.md`）
- 読み込んだら、**保存済みの値にこの画面での編集を重ねたもの**を定義に当てる（`fitValues`。送る側の Rust と
  同じ表 `option_fit_cases.json` を両方が当てる）。定義に無い名前・アプリが決める名前・選択肢に無い値・型の
  合わない値は外し、範囲の外は丸める。変えた値は「エンジンの設定」の先頭に1行（開くと1件1行）で出し、
  **保存するまで確定しない**
- オプションの日本語の名前は読み込みの結果にだけ載り、**保存しない**（`storedDefinitions`）。辞書は Rust の
  `option_labels`（やねうら王を標準。無い名前はエンジンの綴り）

### 解析

| 欄         | 中身                                                                                                                                                                                          |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 候補手の数 | 1 / 3 / 5 / 8 のボタン（押したボタンをもう一度押すと初期値）と「ほかの数…」。上限は `multiPvMax`。値がボタンに無いと数の欄を開いたままにする。空にすると初期値。エンジンへは `MultiPV` で送る |
| 止める条件 | 時間（秒）/ 深さ / ノード数。**保存するが、解析はまだ読まない**（いまは止めるまで読み続ける → #107）                                                                                          |
| 詰み探索   | 同上                                                                                                                                                                                          |

### エンジンの設定

読み込めたとき（定義がいまのエンジンのもので、アプリが決める名前もそろっている。`hasCurrentDefinitions`）だけ
並べる。読み込む前・読めなかったときは「エンジンを選ぶと／読み込めると、ここに設定が並びます」、
読み込み中は「読み込みが終わると、ここに設定が並びます」。

- **1つのリスト**（`optionRows`）: 先頭にスレッド数（`Threads`）とハッシュ（`USI_Hash`）、続けて申告の順
- 名前は日本語、エンジンの綴りを下に小さく。辞書に無ければ綴りだけ
- **出さない**: 値を持たない `button`、アプリが決める名前（評価関数・定跡の欄と解析の固定値）、候補手の数
  （「解析」に置く）、**定跡を使わないときの定跡の設定**
- 欄は型ごと: 選択（check・combo。先頭が「初期値（…）」）、数（欄を離れたときに確定。全角数字・桁区切りは
  読み替え、範囲の外は丸める。読めない・保存済みと同じなら確定しない。`commitSpinInput`）、文字、ファイル
  （文字＋「選択…」。選ぶ画面を開けなければ理由と「欄にパスを直接入力」）。空欄は初期値（送らない）
- 初期値と違う値の行に印。「探す」（日本語でも綴りでも）・「変えた値だけ」・「すべて初期値に戻す」
  （絞り込み中は「表示中の N 件」。**画面に出ている行の値だけ**を消し、解析の節の値は消さない）

新しいプリセットは候補手の数 5 だけを持つ。**読み込んだプリセットには値を足さない。**

### 空欄だけの自動補完

開いた後、候補が揃った時点で**1回だけ**、**エンジンがまだ無い（作ったばかりの）プリセット**の空の欄を埋める
（`autofillPreset`）。エンジンは選べる候補がちょうど1つのときだけ。

**エンジンのあるプリセットの評価関数の空は埋めない。** 空は「指定しない」という選択でもあるので、埋めると
選べない選択肢になる。同じ理由で、下書きが変わるたびには補完しない。

## 状態

| 記号 | 状態           | 判定                        | 出るもの                        |
| ---- | -------------- | --------------------------- | ------------------------------- |
| G0   | 閉             | `open === false`            | 何も描かない（Hook も走らない） |
| G1   | 探している     | `indexStatus === "loading"` | 候補が空のまま                  |
| G2   | 探せなかった   | `indexStatus === "error"`   | 理由を節の上に                  |
| G3   | 編集中         | `indexStatus === "ok"`      | 候補が入った状態                |
| G4   | 入力の誤りあり | `errors` が空でない         | 欄ごとに赤字                    |

下書きと読み込みの状態は `presetDialogReducer`（判定表 `docs/state-transitions/engine-preset-dialog.md`）。

### `engines/` の見せ方

`engines` が何として在るかで帯が変わる（分類は `classifyEnginesDir`）。

| `engines` が   | 帯                                 | 押せる口               |
| -------------- | ---------------------------------- | ---------------------- |
| 読めていない   | 出ない                             | —                      |
| フォルダ       | 出ない                             | —                      |
| 無い           | `engines/ フォルダがありません`    | 「作成」／「探し直す」 |
| フォルダでない | `engines がフォルダではありません` | 「探し直す」だけ       |

帯が映すのは**いま指しているルートの索引だけ**。ルートが変わった直後は走査が返るまで「読めていない」に落ちる。
同じルートを読み直している間は、**帯の「作成」は押せない**（押せると「効かなかった」と読まれる）。

## 操作と結果

| 操作                 | 結果                               |
| -------------------- | ---------------------------------- |
| 「保存」             | 検証 → `updatePreset` → 閉じる     |
| 「キャンセル」／Esc  | 下書きを捨てて閉じる               |
| エンジンを選ぶ       | 裏で読み込む                       |
| 「探し直す」         | `scanAiRoot` をやり直す            |
| 「もう一度読み込む」 | 読めなかったエンジンを読み込み直す |
| 「engines/ を作成」  | `ensureEnginesDir` → 探し直す      |

### 保存時の検証

| 欄       | 条件     | 文言                     |
| -------- | -------- | ------------------------ |
| 名前     | 空でない | 名前を入れてください     |
| エンジン | 空でない | エンジンを選んでください |

**評価関数・定跡は必須でない。** どの名前（`EvalDir` / `EvalFile` / `DNN_Model` …）で送るかは、起動のたびに
エンジンの申告から Rust が決める（[`option-binding.md`](../../state-transitions/option-binding.md)）。

保存時の整形:

- 止める条件は **0 以下を落とす**。時間 0〜3600 / 深さ 0〜999 / ノード 0〜999,999,999。4つとも空なら `analysis` を持たせない
- オプションの**空文字は保存しない**。値は下書きのとおり（**既定値を敷かない**）
- オプションの定義は日本語の名前を外して保存する
- **「使わない」定跡はパスごと落とす**（前の版は解析で使わない定跡のパスを残して保存している。開いて保存し直せば、
  欄の「使わない」とファイルが揃う）

## 失敗の見せ方

| 失敗                   | どこに出るか                                  |
| ---------------------- | --------------------------------------------- |
| `ai_root` を探せない   | 節の上（`indexError`。「探し直す」へ誘う）    |
| `engines/` の作成      | 同上                                          |
| エンジンを読み込めない | エンジンの欄の下                              |
| ファイルを選ぶ画面     | その欄の下                                    |
| 入力の誤り             | 欄ごと                                        |
| 保存そのもの           | 帯（`PresetsFileBridge`）。閉じずに入力を残す |
