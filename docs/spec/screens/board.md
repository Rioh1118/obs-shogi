# 画面仕様: 盤・駒台・操作列

対象: `src/widgets/game-board/` `src/entities/position/`
（指し手の受理・保存は `src/entities/game/`）

状態遷移: [`docs/state-transitions/game.md`](../../state-transitions/game.md)

## 目的

**局面を出し、手を指す。** 指した手は棋譜に入り、そのままファイルへ書かれる。

## 出入口

棋譜が開かれている間、`AppLayout` の本体左側に常駐する。
盤だけを閉じることはできない。

## 画面構成

```
┌─ 後手（上）駒台 ＋ 対局者名 ─┐
│                              │
│        盤（9×9）             │
│                              │
└─ 先手（下）駒台 ＋ 対局者名 ─┘
        ◀◀  ◀  ▶  ▶▶
```

- **駒台の並べ方は駒数で変わる**（`useHandLayout`）。同じ種類は重ねて置く
- 対局者名は JKF ヘッダの `先手` / `後手` を出す。無ければ側の呼称だけ
- `pov=gote` のとき盤ごと反転する。**駒台の上下も入れ替わる**

盤のマスには次の3つの印が付く。

| 印       | 条件                                     |
| -------- | ---------------------------------------- |
| 選択中   | `selectedPosition` がそのマス            |
| 着手可能 | `view.legalMoves` にそのマスへの手がある |
| 直前の手 | `view.lastMove.to` がそのマス            |

## 状態

| 記号 | 状態             | 判定                                 | 見えるもの                   |
| ---- | ---------------- | ------------------------------------ | ---------------------------- |
| P0   | 盤が組めない     | `view.player?.shogi` が無い          | 「盤面を読み込み中...」      |
| P1   | 何も選んでいない | `selectedPosition === null`          | 局面だけ                     |
| P2   | 盤の駒を選択中   | `selectedPosition.type === "square"` | 選択＋着手可能マスの強調     |
| P3   | 持ち駒を選択中   | `selectedPosition.type === "hand"`   | 同上（打てるマスの強調）     |
| P4   | 成りを聞いている | `promotionState !== null`            | 移動先のマスに成／不成の選択 |

`P4` の間、盤のクリックは**すべて無視される**。

## 操作と結果

| 操作                         | 結果                                             |
| ---------------------------- | ------------------------------------------------ |
| 自分の手番の駒をクリック     | 選択（P2）。着手可能マスが光る                   |
| 同じ駒をもう一度クリック     | 選択解除                                         |
| 着手可能マスをクリック       | 指す。成れる場合は先に成／不成を聞く             |
| 着手可能でないマスをクリック | そのマスを選び直す（`selectSquare` に落ちる）    |
| 持ち駒をクリック             | 選択（P3）。**手番でなければ選択を解除するだけ** |
| 盤・駒台の外を押す           | 選択解除（`AppLayout` が拾う）                   |
| ◀◀ / ◀ / ▶ / ▶▶              | 最初 / 前の手 / 次の手 / 最後                    |

### 成りの確認

`mustPromote` なら聞かずに成る。`canPromote` なら移動先のマスの上に
`PromotionDialog` を出し、答えを待ってから指す（`Promise` で待つ）。

**待っている間に局面が変わったら取り消す。** 手数（`player.tesuu`）の変化を
監視していて、変わっていれば選択ごと捨てる。

### 指した手の行き先

`makeMove` は棋譜（`state.jkf`）を書き換え、`GamePersistence` を通して
**ファイルへ即書き込む**。分岐の途中で指した場合は変化として枝が増える。
失敗すると棋譜はメモリ上で元に戻る。

## 失敗の見せ方

**盤の中には失敗を出す場所が無い。**

| 失敗                     | いま起きること                                        |
| ------------------------ | ----------------------------------------------------- |
| 手が不正                 | 何も起きない（`legalMoves` に無いので指しに行かない） |
| 棋譜への書き込みが落ちた | メモリ上の棋譜は戻る。**画面には何も出ない**          |
| 局面が組めない           | 「盤面を読み込み中...」のまま止まる                   |

`makeMove` は `Err` を返し `state.error` にも積むが、**それを描いている場所が無い**
（`entities/game` の `error` の読み手は0）。→ #277 ／ ADR-0004

## いま満たしていないこと

- **書き込み失敗が利用者に届かない**（上記）→ #277
- **駒をクリックしても手番でなければ何も起きない。** 理由は出ない
- **`Board.tsx` に空の `useEffect` が1つ残っている**（`promotionState` を見るだけで何もしない）
- **駒のクリックで `console.log` を出している**（`PieceFactory` の `onClick`）
- **`AppErrorBoundary` が盤を包んでいない。** ここで throw すると `/app` が畳まれる
- **`JKFPlayer.logs` に再生ログが無制限に積まれる** → #211

## これからの要件

盤は**局面編集モード**の入口になる。編集中は次が変わる。

- クリックの意味が「指す」から「置く／取る／裏返す」へ変わる
- 手番と持ち駒を直接いじれる
- 駒落ちの配置を選べる

→ [features/position-edit.md](../features/position-edit.md)

対局中は「自分の手番でだけ指せる」「相手の手番では盤を触れない」が要る。
→ [features/game-play.md](../features/game-play.md)
