# 直された理由を残す

人が成果物を直したら、**その場の修正で終えない。**

1. 直す
2. 「どうすれば起きなかったか」を自分で振り返る
3. `.claude/knowledge/correction-log.md` に1件書く（日付 / 起きたこと / 次からすること / 理由）
4. 振り分けて反映する

| 何に効くか     | 反映先                                                      |
| -------------- | ----------------------------------------------------------- |
| 機械で落とせる | テスト・lint・ラチェット                                    |
| その工程だけ   | その工程の skill                                            |
| 全工程に効く   | 同じ原因が2件そろったら `CLAUDE.md` か `.claude/rules/`     |
| 1回限りの好み  | 記録だけ                                                    |

**足すときは書き換える。** 長くなったら `/skill-care` で圧縮する。
