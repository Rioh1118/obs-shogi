# 点検表

手順2で使う。**候補を出す道具で、判定ではない。** 意図があれば残す。

| 見るもの | よくある崩れ |
| -------- | ------------ |
| 角丸 | 面の役割より大きい。外より内が大きい。札（pill）を状態以外に使う |
| 枠 | 枠の中に枠。枠・影・面の色を同時に使う。区切りを線でしか作れていない |
| 階層 | 題・本文・補足が同じ太さに見える。太字が多すぎて強調が消える |
| 余白 | 関係の近いものと遠いものが同じ間隔。同じ役割で値が違う |
| 配分 | 部品の大きさで画面を埋めていて、基準へ寄せると余りが出る。中央のつもりが、既定の余白で見た目だけずれる |
| ボタン | 行いっぱいに伸びる。主ボタンが1画面に複数。同じ操作が隣に2つ |
| 色 | 意味の無い色。薄くする方法が複数ある |
| 密度 | 説明文が操作より多い。1項目が画面を占める |
| 語 | 内部の綴りがそのまま出る。題と欄が同じ語 |
| 記号 | 飾りのアイコン。絵文字。語と意味が重なるだけの記号 |
| 状態 | 長い文字列で崩れる。空や失敗だけ別の見た目 |

別の製品の DESIGN.md や公開の規則集は考え方を借りる。そのまま入れない（`/skill-care`）。
