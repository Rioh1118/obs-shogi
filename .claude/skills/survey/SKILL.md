入力は `.claude/plans/<slug>/ledger.md` の `要調査` の行。**証拠の等級と規律は `research/README.md` が持つ。
先に読む。ここに写さない。**

## 手順0: 手持ちを確かめる

`research/`、`shogi-home-spec.md`、`obs-shogi-spec.md`、`.claude/knowledge/usi_protocol.md` に既にある事実を
棚卸しする。**どれも取った時点の写し**なので、判定に使うものは版を確かめて取り直す。

## 手順1: 調べ方を宣言する

問い × 対象の表を先に作る。各セルは **実施 / 非該当 / 後段 / リスク受容** のどれか。空欄を残さない。

対象は立場の違うものを選ぶ。

| 対象       | 例                                    | 取り方                                    |
| ---------- | ------------------------------------- | ----------------------------------------- |
| 規格       | USI の原典                            | 原文を開く。解説記事で代えない            |
| 公開実装   | ShogiHome、ほかの保守されている GUI   | ソース。コミット SHA とファイルパスを書く |
| 閉じた実装 | 配布のみの GUI                        | 実機・公式の説明。等級は `[推定]` まで    |
| 実エンジン | やねうら王系、DL 系など申告の違うもの | 実際に `usi` を送った出力を残す           |

完了: 台帳の全 `要調査` が表の行にある。

## 手順2: 調べる

- 事実は `research/<対象>/` へ。**方針を書かない**（方針はこの後の判定表）
- 版を固定する。「無い」と言うなら探した場所と検索語を書く
- **仕様が頼る前提は、仕様を書く前に実機で測る。** 計画を実装で覆す手戻りは、測れば前で止まる
- 公開の skill や実装を読むのは参考まで。**入れない。写さない**

agent に割るなら対象ごとに。本数は `.claude/rules/agents.md` に従う。

## 手順3: 比べる

論点ごとに、対象を列にして並べる。**同じ論点の粒度で揃える。**
差が出た論点だけでなく、揃っている論点も残す。そこが標準の候補になる。

| 揃い方                           | 読み方                           |
| -------------------------------- | -------------------------------- |
| 規格が定める                     | **標準**。外れるなら理由が要る   |
| 規格に無いが立場の違う実装が揃う | **事実上の標準**                 |
| 1実装だけ                        | その実装の選択。標準と呼ばない   |
| 割れている                       | 標準は無い。選ぶ理由を自分で持つ |

## 手順4: 判定表を作る

`.claude/plans/<slug>/survey.md` に書く。

| 論点 | 揃い方 | 判定 | 理由 | 根拠 | 与件 ID |
| ---- | ------ | ---- | ---- | ---- | ------- |

**判定**: 標準に寄せる / 独自を保つ / 採らない / 保留。

- 判定は `docs/PREMISES.md` の軸に乗せる。**「ShogiHome にあるから作らない」「あるから作る」を理由にしない**
- 非ゴールと衝突する標準は「採らない」と書く。黙って落とさない
- 標準に寄せると既存データや操作が壊れるなら、移行の要否を理由に書く

## 手順5: 別の目で確かめる

**調べた本人が採点しない。** 判定に使った主張を抜き出し、fresh な agent 1本に、主張と出典だけを渡して
開いて確かめさせる。会話の経緯は渡さない。

外れた主張は等級を落とす（`[反証]` / `[判定不能]`）。判定が動いたら表を直す。

## 手順6: 台帳へ戻す

- 各行の状態を更新する。新しい論点が出たら `/intake` の手順4へ戻る
- 判定は人が承認する。**調査は材料で、決めるのは人**
- 残すべき仮定は `docs/PREMISES.md`、未決は `docs/OPEN-QUESTIONS.md` へ

完了:

- 全 `要調査` が解けたか、等級つきで保留になっている
- 判定表の全行に根拠の出典がある
- 別の目の検査を通した主張の数と、外れた数を書いた
