# ADR の形（MADR）

番号は `docs/decisions/` の次の番号。ファイル名は `NNNN-<slug>.md`。

```markdown
# ADR-NNNN: <解いた問題と決めたことが分かる題>

- 状態: 採用
- 日付: YYYY-MM-DD
- 決めたもの: `/decide`（人の確認なし）

## 文脈と問題

<なぜ今決めるか。2〜3文か、1文の問い>

## 判断の基準

<効いた基準を優先順に。`docs/rules/decisions.md` の ID を付ける>

## 検討した選択肢

- <案1>
- <案2>

## 決定

「<案1>」を選ぶ。<最初に差がついた基準と理由>

### 結果

- 良い: <得られるもの>
- 悪い: <諦めるもの>

## 戻し方

<どう戻すか。一方通行を変換したなら、その手>
```
