### R-03 (HIGH, robustness / comment): 参照リンクの検査が、正しく描画される書き方を「消し忘れ」と報告する

`brokenReferencesInBody` が拾う使用の形は `[表示][ラベル]` と `[ラベル][]` だけ。
**CommonMark の shortcut 参照 `[ラベル]` を拾っていない。** 実際に通した結果:

```
"本文 [shogihome-yaneuraou] を見る\n\n[shogihome-yaneuraou]: https://x/\n"
→ [{"label":"shogihome-yaneuraou","reason":"unused-definition"}]
```

これは**リンクとして正しく描画される** markdown。しかも r1 で入れた規約
（参照名は `<リポジトリ名>-<対象>`、定義はファイルの末尾）に従って同じ出典を2度目に引く人が
最も自然に書く形。

筋道: 2度目を `[shogihome-yaneuraou]` と書く → 検査が「**使われていない定義。消し忘れ**」で落ちる
→ 言われたとおり定義を消す → **元からあった `[…][shogihome-yaneuraou]` が角括弧つきの地の文に落ちる**
→ 使用も定義も無いので検査は緑。

**この検査が塞ぐと宣言した退行を、この検査の失敗文言が自分で起こす。**

偽陽性はもう1つ確認した。表のセルの地の文が当たる。

```
"| 列 | [必須][任意] |\n" → [{"label":"任意","reason":"no-definition"}]
```
