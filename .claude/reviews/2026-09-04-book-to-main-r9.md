## 所見

### Z-01 / Z-04 (MEDIUM, 3人): 畳む操作の免除が、畳んだ条件から落ちている

r8 の Y-02 で素通しの条件を1つに畳んだ。畳んだ形は「見えた変更のどれも種類に当たらないとき」だが、
**`git rebase --abort` は種類に当たる変更が見えていても素通しする** —— `gate_is_teardown` が
`needs_*` を潰すため。reviewer がゲート本体を複製して再現した。

害は「未検証のコミットが入る」側ではなく**案内の側**に出る。競合を抱えた人が「種類に当たる
変更があるのだから deny される」と読み、**畳む手段が無いと判断して `git reset --hard` や
競合の片側埋めへ回る** —— 実装では免除して塞いだ行き止まりが、規約の側で読み手の頭の中に復活する。

免除をもう1つ書き足すと、次の免除でまた同じ所見が出る。**網羅の名乗りをやめた**
（パス→種類の対応で既に採っている扱いに揃えた）。判定表の S4 行も、判定条件が
`--untracked-files=no` を落としていて行き先も畳む前の形のままだった。

- 結果: 対応済み `8597bb62`（`CLAUDE.md` と判定表）、`59ec4f86`（ゲート本体のヘッダ。
  **1本目で当てたつもりが当たっていなかった** —— 置換の失敗を確かめずに commit した）

### Z-05 (MEDIUM, 2人): 「Rust の `#[test]` が0個」が3箇所にあり、この PR の入れるラチェットと矛盾する

> **r10 で訂正**: 3箇所ではなく4箇所だった（`.claude/skills/review-protocol/SKILL.md` を数え落とした）。
> 残りは r10 の AA-01 で直した。

実測は `src-tauri/src` が 244、`src-tauri/tests` が 22。**`main` の時点でも 90 で、0 は一度も
真になっていない。** この PR はさらに「下回ったら落ちる」ラチェット（`test_count_ratchet.rs`）を
持ち込むので、自分が入れる機構と正面から食い違う。

`implement/SKILL.md` は実装前に必ず読ませる手順書。そこが「0個」と断言していると、読んだ人は

落ちても信じない、という形で出る。

`CLAUDE.md` は自分で「件数をここに書かない」と定めているのに、同じ節の2行下で「大半がベンチ」

- 結果: 対応済み `9d63ad6d`（件数と「0個」を落とし、現在値の出典を `EXPECTED_MIN` に寄せた）

### Z-02 (MEDIUM, 2人): 「実装を読むこと」で届かない場所が1つある

`b138443a` は後勝ちへ替える手順を doc から落とし、代わりに踏むものを5つ挙げて
「現物を開くこと」とした。**5つのうち一次資料の表だけが Rust のツリーの外にある。**
`docs/state-transitions/yaneuraou-db-parse.md` の2行が、この差を本家との差として記録している。

替えた人は5つを実装から見つけて、**表だけを「先勝ち」のまま残す。**
この表は差が消えれば行ごと落ちるべきもので、grep も `cargo` も届かない。

- 結果: 対応済み `e4e05ade`（置き場を1行で指した。手順は書かない ——
  それはこの doc が持たないと決めた側）

### Z-06 (MEDIUM, 1人): 免除の理由が `--skip` に当たらない
