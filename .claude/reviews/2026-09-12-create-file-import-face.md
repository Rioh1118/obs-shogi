**提案どおりに直さなかったもの**

- **`KifuParseError` の文言に「どうすればよいか」を足す**（robustness [HIGH]）——
  出典に足さず、**面の側で添えた**。同じ失敗はファイルを開く経路でも起きるので、
  出典に「貼り付けてください」と書くと、貼ってもいない利用者へ貼り直しを求めることになる
- **`$create-file-side-width` を feature 側へ戻す**（architecture）——
  骨格の作り直しで右の列そのものが無くなり、争点が消えた
