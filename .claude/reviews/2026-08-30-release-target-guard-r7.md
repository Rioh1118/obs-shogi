### [MEDIUM] R7-1 `[arch]` を固定したときに壊れる筋道が、`tauri-action` の実装と食い違う

- 場所: `.github/workflows/release.yml` / `docs/RELEASE.md`（reviewer: comment）
- 根拠: reviewer が現物を引いた。`src/utils.ts` の `getAssetName` は資産にも `.sig` にも
  **同じパターン**を描画し、`src/upload-version-json.ts` は sig 側の名前から最後の拡張子だけを
  落として突き合わせる。`[arch]` を literal にしても両側が同じ literal になるので、
  **突き合わせは常に一致する**。
  実際に壊れるのは別の筋道: `[platform]` は macOS の2 leg とも `darwin` なので、
  `[arch]` を固定すると**同名の資産を出す**。`upload-release-assets.ts` は同名の既存資産を
  delete してから上げ直すので、後から走った leg が先の資産を消す。
- なぜ問題か: `latest.json` から macOS の片方が欠けた事故を追う人は、コメントに従って
  署名の突き合わせを調べる。そこには何も無い。R6-5 で潰したのと同じ「読んだ人が別の場所を探す」形。
- 直し方: 実態（2 leg の資産名衝突）に書き換え、yml と doc の二重持ちも yml 側へ寄せた。
- 導入コミットの sha: `e6ed584` / `24a3832`（**ラウンド2・5で私が入れた**）

- 直し方: 「撃ち直す前に、前の run が終わっているか見る。止めるならキャンセルする」を足した。
