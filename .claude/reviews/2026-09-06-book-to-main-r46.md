## BLOCK の中身

**r45 の直し方に穴が2つ残っていた。** どちらも使い捨ての repo で、
**空のファイルが実際にコミットされる**ところまで再現した。

1. 引用潰しの sed がトークン境界に錨づけられておらず、左から順に対にする。
   二重引用符の中のアポストロフィ2つが「引用」として対になり、
   その間にある本物のリダイレクトごと消える。

   ```
   git commit -m "don't" > src/app/App.tsx "won't"
   ```

2. `GATE_OPT_VALUE` が `>` を飲むので、リダイレクトが `$call` の**内側**に入る。
   prefix は空、suffix は残りだけ、`case` は置換しか見ないので、
   手前も後ろも見ている検査の**どれにも当たらない**。

   ```
   git -c user.name=x>src/app/App.tsx commit -m y
   git -q>src/app/App.tsx commit -m y
   ```

`-c` に限らず任意の `-` 付きトークンで成立する。

## 機械を増やしたもの

**コメントが指すファイル名の実在**を見る検査を足した（`comment_identifiers.rs`）。
`is_identifier` は下線を含む綴りしか候補にしないので、`sfen.rs` のような
ファイル名は拾えず、関数名が実在する限り緑のまま通っていた。

**入れた時点で4件見つかった。3件は #429 側。**

| 場所                             | 指していた先          | 実際                    |
| -------------------------------- | --------------------- | ----------------------- |
| `search/cache/paths.rs`          | `index_cache.rs`      | `cache/format.rs`       |
| `crates/test-support/src/dir.rs` | `search/test_kifu.rs` | 同じ crate の `kifu.rs` |
| `src/book/error.rs`              | `api.rs`              | `commands.rs`           |
| `verify-gate.test.sh`            | `api.rs`（標本）      | `commands.rs`           |

依存クレートの中身を指す言及は `EXEMPT_FILES` に理由つきで置き、
**免除が死んでいないこと**も見る。

あわせて `expect_*` が `count_run` を呼ぶことを `compgen` で自己検査するようにした
（呼び忘れると床が上がらないまま assertion が増える）。
