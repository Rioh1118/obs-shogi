## #215

- 同じ場所への保存: 一時ファイル名は `foo.kif` に対して必ず `foo.kif.tmp`。`create(true).truncate(true)` は symlink を辿るので、root 配下に同名の symlink があると root の外のファイルを 0 バイトにする。保存が重なると一時ファイルを共有し、「保存できました」で確定するのが別の内容になる
- 同期のコマンド: Tauri の同期コマンドは IPC ハンドラで走る。ツリーの取得は木を全部作るので、その総時間だけウィンドウが固まる。`delete_directory` の再帰削除も同じ
- Windows の名前: `create_directory(parent, "研究.")` は `研究` を作り、返り値と次のツリーの値が食い違う。`CON` / `PRN` / `NUL` / `COM1` は未処理。`str::trim` が落とすのは空白だけ
- root の検査: `save_config` に `root_dir: "/"` を渡してからツリーを取ると、全ファイルシステムが返り、任意の `.kif` が読める。`open_project` は受けた root の下を歩いて棋譜を読む
- serde 名: Rust のテストの配列は手書き、TS のテストは変種名から snake_case を作るだけで、入れ忘れた変種はどちらの照合も受けない

- 畳んだ後: 2.068 μs/query（22倍）
