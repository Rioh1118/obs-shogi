### [HIGH] R5-01 NUL の割合の閾値が、本物の UTF-16 を落とす（r4 の退行）

- 場所: `search/kifu_reader.rs` の `utf16_by_nul_layout`
- reviewer: **3人とも**（全員が実測）
- `(even + odd) * 4 < bytes.len()` は UTF-16 では
  「文字の半数以上が ASCII であること」と同値。**全角の多い棋譜ほど落ちる**

  | 題材（UTF-16LE）   | NUL の割合 | 判定     |
  | ------------------ | ---------- | -------- |
  | 指し手行だけの KIF | 36.5%      | UTF-16LE |
  | 注釈の多い KIF     | 13.6%      | **None** |
  | KI2（全角主体）    | 10.0%      | **None** |

- 落ちると「どの文字コードでも読めなかった。棋譜ではないファイルに拡張子が
  付いていないか」と出て、**中身が正しい棋譜を「棋譜ではない」と疑わせる**
- **r4 の前は正しく出ていた。** R3-01 で立てた振る舞いを閾値で潰していた
