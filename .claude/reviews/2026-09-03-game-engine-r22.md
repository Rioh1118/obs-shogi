- 腕が1つだけの `match ch { '{' => .., _ => {} }`

拾える形（`find('{')` / `contains('{')` / 折り返した引数 / `c == '{'` /
`b != b'{'` / `matches!` / `trim_start_matches(['{','}'])`）は doc どおり動いている。

**実測すると見逃しにはならない。** 囮を足しても本物の関門の位置は一覧に残るので、
存在確認がそれより前にあれば拾える。HEAD の写しと差分を取って確かめた。

綴りが変数まで一致する文字列を存在確認の**後ろ**に置くと、順序が正しいコマンドが
違反として出る。危険度は所見より低いが、緑を信じられなくする向きなので直した。
