## 所見

### [BLOCK] 1. 畳まれた後に着地した席の停止が落ちると、返し直す者が居ない

reviewer: robustness / react（独立に実測）。こちらで再現し、テストを置いた。

▶ の開始が往復の途中で畳まれ、**席が畳んだ後に着地**して、その席を捨てる停止が落ちる回。
`sweepOnUnmount` はもう走り終えているので、`keepOrForget` が欄へ書き戻しても誰も撃たない。

```
# 現物  → 赤（[undefined, "unmount"] が飛ばない）
AssertionError: expected [['session-late','late-start']] to deep equally contain [undefined,'unmount']
```

r28 で直した側と**結末は同じ**（席が Rust に残る）なのに、**停止を撃った時刻が
畳む前か後かだけで分かれていた**。

### [BLOCK] 2. その直しが、生きている画面へ指さない停止を撃つ形を作った（**こちらの退行**）

reviewer: react（実測）

`sweptRef` を cleanup で立てるだけにしたので、同じインスタンスに setup → cleanup → setup が
走る回（StrictMode）に立ったまま残る。以後その画面は「畳まれた」ものとして扱われ、
捨てる停止が1回落ちただけで `stop_all_sessions` が飛ぶ——Rust は席を**全部**空けるので、
別の口が取った席まで巻き添えにする。

```
現物(HEAD)  : [["s1","restart"],["s2","late-restart"]]
直した版    : [["s1","restart"],["s2","late-restart"],[null,"unmount"]]   ← 畳んでいない
```

隣の `unmountedRef` は同じ理由で setup に戻す行を持ち、doc にもそう書いてある。
**印を1つ足したときに写し忘れた。**
