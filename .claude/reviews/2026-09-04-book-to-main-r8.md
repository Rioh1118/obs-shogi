2つの条件に分けて書いたが、**その両方に当たらないのに素通しする形**があった ——
種類外の追跡済み変更（`.claude/**` の `.md` など）がツリーにあり、かつ新規の `.rs` を
`git add -A && git commit` で入れる形。**このリポジトリのラウンド運用そのものの形。**

reviewer がゲート本体を複製して再現した。`git status` は空ではない（種類なしの行が出る）が、
`needs_*` は1つも立たず exit 0。読み手は「1つ目は違う、2つ目も違う」と読んで
**検証が走ったと結論する。走っていない。**

- 結果: 対応済み `cbb80355`（`needs_*` は「見えた行のうち種類に当たるもの」から立つので、
  **条件を1つに畳んだ**。判定表の (B, S4) と B 行も同じ形へ）

### Y-03 (MEDIUM, 1人が実測): 巻き戻しで消えるのは、`--fix` が当てた整形だけ

書かれていないので、整形が当たった直後に lint で落ちた人は、整形が巻き戻ったことに
