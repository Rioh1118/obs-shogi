## 直した（8件）

### 代（epoch）の穴が3つ

**代を入れたとき掛けたのは全件構築の3点だけだった。**

| 穴                             | 何が起きるか                                                                                                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `restart` が代を返さない       | 構築タスクが起きたときの索引から代を拾う。`restart` から spawn までに全走査が挟まるので、その窓で2本目の `open` が入ると**1本目が2本目の代を採用する**。両方が同じ代を名乗り、どちらの書き込みも通る                |
| 差分適用が素通し               | 前の `root_dir` と `scan` を持ったまま差し替わった索引に書く。**前の `file_id` で墓標を立てて別の棋譜のヒットが黙って消える**。`Ready` も無条件に上げるので、**半分しか入っていない索引が「最新」として画面に並ぶ** |
| 保存時に `snapshot` を拾い直す | 別の `open` が差し替えた索引をこのプロジェクトの名前で焼く。次回の復元で「空の索引 + 全ファイル分の `scan`」が戻り、**差分ゼロで検索が恒久的に0件**になる                                                           |

**2つ目は `docs/state-transitions/search.md` が「同じ `store` に書く」と名指ししている当の経路。**
代を入れたのに、その doc が名指しした側を守っていなかった。

直したうえで、**走っているタスクに素の `update` が現れたら落ちるラチェット**
（`tests/index_writes_are_guarded.rs`）を足した。本番の素の `update` は0件。

### 往復のテストが中身を1件も見ていなかった

「保存経路にテストを通す」と報告したテストが**スカラ2つしか見ていなかった。**
桶の書き出しを潰す変異も、節表を捨てる変異も緑のまま通る。
**`Codec` の doc が約束する「往復すること」の実体が1ビットも固定されていなかった。**

CLAUDE.md の「変異を当てて落ちることを確かめる」を満たしていなかった。

### 置き場の失敗が3つ

| 穴                             | 直し方                                                                                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `flush` だけで耐久化していない | `std::fs::File` の `flush` は何もしない。置き換えの直後に OS ごと落ちると**本体は在るのに中身が空**で、その時点で退避は消してある。`sync_all` に |
| 置き場を作れない腕が空         | ログも出ないので、キャッシュが一度も書かれないまま毎起動で全件構築                                                                               |
| 退避の腕が2つあって同じ        | `NotFound` だけ特別扱いに見えるが実際は `Io` でも落ちる。畳んだ                                                                                  |
