# Button

状態：規則は基準線（v0.1。製品の `docs/spec/design-language.md` §5、ADR-0005、ADR-0013 から写した）。見本実装の値は仮で、製品の Button の高さ・余白をまだ写していない
トークン：`button.*`（design_system/tokens/component/button.tokens.json）

## 用途

画面上で操作を実行する。保存、作成、削除、ダイアログを開く、など。

## 使わない場面

- 別の画面へ移動するだけ → リンクを使う（見た目をボタンに寄せない）
- 選択肢から1つを選ぶ → 区切りボタンか選択（`_index.md`）
- 行の余りを埋めるために幅を伸ばす → 押すものは文字の幅。余りは入力欄が受け持つ

## 役割

**役割で選ぶ。迷ったら中立。確定は1画面に1つ。**

| 役割 | いつ使う | 見た目 | 例 |
| --- | --- | --- | --- |
| 確定（primary） | 画面の結果を確定する。1画面に1つ | 砂色の背景（`color.commit.solid`）に暗い文字 | 保存、作成 |
| 進める（accent） | 次の一手を進める。確定ではない | 銅の枠に銅の文字（`color.text.accent`）。背景を敷かない | フォルダを作成、選択… |
| 中立（neutral） | それ以外 | 枠のボタン（`color.border.default`） | キャンセル、閉じる |
| 危険（danger） | 取り消せない操作の確定 | 危険色の背景（`color.feedback.danger.solid`）に暗い文字 | 削除 |

`もう一度読み込む` は、失敗の第一手なら進める、他に次の一手があれば中立（利用者、2026-10-31）。
見本実装の `primary` / `secondary` は、確定 / 中立 に当たる。進める と 危険 の見本はまだ無い。

## 状態

| 状態 | 表し方 |
| --- | --- |
| 通常 | 上の表のとおり |
| ホバー | **背景に載る文字の色で向きを決める。** 白文字を載せる背景は暗くする、暗い文字を載せる背景は明るくする（`*.solid-hover`）。明るくして比が下がると、押す瞬間にいちばん読みにくくなる。枠のボタンは白の薄い背景（6%）を敷く。進めるは背景を敷かず枠を明るくする |
| 押下 | 1回押すボタンは沈ませる。増減と区切りは連続で押すので沈ませない |
| フォーカス | 固定のフォーカスリング（`focus.ring.*`）。変更不可 |
| 無効 | 不透明度 0.45 だけ。色を変えない |

動きは `duration.3` で応える。

## 大きさ

sm 28px / md 32px / lg 40px。フォームの行は md。文字は `font.size.aux` の `font.weight.strong`。角丸は `radius.control`。

## アクセシビリティ

- 文字と背景は 4.5:1 以上、境界線と背景は 3:1 以上（design_system/tokens/contrast-pairs.json で検査）。
- ボタンの文言だけで何が起きるか分かるようにする（「OK」「はい」にしない）。
- 種類は送信なら submit、それ以外は button を明示する。

## 良い例・悪い例

- 良い例：`examples/good/button-usage.*`
- 悪い例：`examples/bad/`（各ファイルの先頭に、どの規則に違反したかを書いてある）

## 文言

漢語は体言止め（`保存` `削除`）、和語は言い切り（`開く` `閉じる`）。`〜する` を付けない。別の画面を挟むなら `…` を付ける（`design_system/content/voice-and-tone.md`）。
