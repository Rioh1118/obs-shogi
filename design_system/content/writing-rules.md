# 表記ルール

状態：基準線（v0.1）。製品の今の規則（製品の `docs/spec/design-language.md` §6「表記」、2026-11-08）から写した。

| 項目 | 規則 |
| --- | --- |
| 省略記号 | `…` 1文字。`...` を使わない |
| 括弧 | 日本語の文では全角 `（）`。引用とボタン名は `「」` |
| 英数字 | 半角。日本語との間に半角スペース（`AI ライブラリ`）。数字と単位は続ける（`3秒`） |
| 感嘆符 | 使わない |
| ひらがなで書く語 | `ください` `かかる` `そろう` `つながる` `できる` `とき` `もの` |
| 数の単位 | 欄の名前に括弧で添える（`ハッシュ（MB）`）。値の側で繰り返さない |
| 記号 | アイコンの集合1つだけ（製品では `lucide-react`）。絵文字を画面に使わない |
| 数の書体 | 等幅（表形式の数字）。桁が揃わないと並びを読めない |
| 名前と綴り | 名前を主にし、機械の綴り（エンジンの名前など）は下に注記の大きさで添える。綴りを主にしない |
