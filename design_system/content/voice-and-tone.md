# ボイスとトーン

状態：基準線（v0.1）。製品の今の規則（製品の `docs/spec/design-language.md` §0・§6、2026-11-08）から写した。旧 Polaris の content と GOV.UK のスタイルガイドの構成に倣う（文章は持ち込まない）。

**画面の文章は、標準的な業務アプリの日本語で書く。** 言い回しで個性を出さない。和語に開いた独自の言い方より、利用者が他のアプリで見慣れた語を選ぶ（利用者の修正「数を入れてください」→「数値を入力してください」、2026-10-31）。性格（記録係：正確・行き届く・寡黙）は語の選び方と出すかどうかで表し、言い回しでは表さない。

## ボイス（いつも同じ性格）
- 敬体 / 常体: 文は です・ます で句点を打つ。状態の語、欄の名前、ボタンは句点なし
- 一人称: 使わない
- 呼びかけ方: 使わない（「あなたの」と書かない）

## トーン（場面で変える度合い）
| 場面 | トーン | 例 |
| --- | --- | --- |
| 成功 | 出さない。うまくいった段階は黙る | （何も出さない） |
| エラー | 何が起きたか。次にすること。の2文。謝らない | 棋譜を読み込めませんでした。ファイルの形式を確認してください。 |
| 空状態 | 理由と次の一手を言う。「何もありません」で終えない | 棋譜を選択するか、作成してください |
| 待ち | 何を待っているかを言う。終わる見込みのあるものだけ | エンジンを起動しています… |
| 確認（取り消せない操作） | 何が無くなるかを名指す。ボタンは動作の語 | 「削除」（「OK」「はい」にしない） |

## 文の形
- ボタン：漢語は体言止め（`保存` `削除` `再起動` `棋譜を作成`）。和語は言い切り（`開く` `閉じる` `もう一度読み込む`）。`〜する` を付けない。`OK` と `はい` を使わない（利用者、2026-10-31）
- エラー：起きたことは `〜できませんでした。` に揃える。`〜に失敗しました` を使わない。理由は文の後に全角括弧 `（…）` で添える。`: ${e}` の形にしない
- 見出し：名詞か「〜を＋漢語」（`設定` `局面検索` `局面を保存`）。同じ操作の題とボタンは同じ語
- 欄の名前：名詞。値の入れ物を名乗る
- 別の画面へ進むボタン：語に `…` を付ける（`選択…`）。押すと確認か選択が挟まる
- 入力の断り：直し方だけを1文で。起きる動作の説明を足さない（`数値を入力してください`）
- 待ち：`〜しています…`。項目の状態なら `〜中…`

## 使わない表現
- 内部の語を画面に出さない：申告、取得、プローブ、席、セッション、ランタイム、ready、`isready`（利用者、2026-09-30）
- 感嘆符
- 謝罪（「申し訳ありません」）
- 1語で2つの動作を指すこと（用語集の 中断する／中止する／キャンセル／閉じる を混ぜない）
