# ライセンス本文

`THIRD-PARTY-NOTICES.md` の「ライセンス本文」の節に、そのまま貼られる。
貼るのは `scripts/generate-third-party-notices.mjs`。

**著作権行を含めない。** 権利者は依存ごとに違い、生成器が各パッケージの `LICENSE` から
拾って表の「著作権表示」欄に並べる。本文の側にも1人分だけ書くと、
その1人がすべての依存の権利者であるかのように読める。

ファイル名は SPDX の識別子。依存の `license` に出てきた識別子の本文が無ければ生成器が落ち、
どの依存も使っていない本文が残っていても落ちる。**どちらも黙って通さない** ——
通知が足りない状態と、置いた当時の依存を指したまま古びた本文を止めるため。

新しい識別子の本文は、その依存自身が同梱している `LICENSE` から写すのが確実。
**そのライセンスで配ってよいかを決めるのは人の仕事で、生成器はそこを見ない。**
