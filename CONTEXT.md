# 用語集

同じ概念に同じ語を使うための表（ルール `R-NAM-2` と `R-MSG-2`）。**新しい語は、コードより先にここへ足す。**
中身は語の定義だけ。仕様と実装の詳細は書かない。

語彙を ADR が決めている領域は、ADR が正本。ここには入口だけを置く。

- 対局: [ADR-0011](docs/decisions/0011-game-vocabulary-and-placement.md) 決定1
- ドックとビュー: [ADR-0010](docs/decisions/0010-dock-tabs-and-view-vocabulary.md)
- 画面の将棋の語: [ADR-0012](docs/decisions/0012-shogi-gui-vocabulary.md)。一覧は `docs/spec/design-language.md` の「将棋 GUI の語」

## 書き方

| 列           | 書くもの                                      |
| ------------ | --------------------------------------------- |
| UI の表記    | 画面に出す語。画面に出ない語は `—`            |
| コードの名前 | TS と Rust の綴り。USI の語は `USI:` を付ける |
| 意味         | 1文の定義                                     |
| 使わない語   | 同じ意味で使わない語                          |

## エンジン

| UI の表記      | コードの名前                       | 意味                                                        | 使わない語        |
| -------------- | ---------------------------------- | ----------------------------------------------------------- | ----------------- |
| プリセット     | `EnginePreset`                     | 1つのエンジンを何で動かし、どう検討するかの組               | プロファイル      |
| エンジン設定   | `EngineSettingsSection`            | エンジンが申告したオプションの一覧                          | 詳細設定          |
| 検討           | `analysis`                         | エンジンに局面を読ませ続けること。コードの名前は変えない    | 解析（画面で）    |
| 候補手の数     | `multiPv` / `USI: MultiPV`         | 検討で並べる手の数                                          | MultiPV（画面で） |
| 評価関数       | `aiName`（名前が実態とずれている） | エンジンが読む評価の重み。`aiName` は入っているフォルダの名 | プロファイル      |
| 定跡           | `book`                             | 検討と定跡ビューで使う定跡のファイル                        | ブック            |
| AI ライブラリ  | `ai_root`                          | エンジン・評価関数・定跡を置くフォルダ                      | AI_ROOT（画面で） |
| —              | `EngineSeat` / `AnalysisSessionId` | 席。Rust の `active_sessions` の1エントリで、走っている探索1本の持ち分 | —                 |

## 棋譜

| UI の表記 | コードの名前    | 意味                                          | 使わない語       |
| --------- | --------------- | --------------------------------------------- | ---------------- |
| 棋譜      | `entities/game` | 1局の指し手と分岐の記録。走っている対局とは別 | ゲーム（画面で） |
| —         | `KifuCursor`    | 棋譜の中のいまの位置                          | —                |

## 別の意味で使われている語

| 語     | 注意                                                                                                                   |
| ------ | ---------------------------------------------------------------------------------------------------------------------- |
| 検討   | 画面ではエンジンに読ませ続ける機能（上の表）。設計の議論の意味では使わない（`research/README.md`）                     |
| 解析   | 画面では使わない。棋譜全体を読ませる機能のために語を取っておく（ADR-0012）。棋譜の読み取りの失敗は `読み込む` で言う                 |
| 閉じる | 面を消す動作だけを指す。対局を終える動作には使わない（ADR-0011）                                                       |
| 席     | エンジンの文脈では上の表の1エントリ。対局では先手と後手のそれぞれで、人かエンジンが座る（ADR-0011）                    |

## 揺れが残っているもの

見つけたら行を足す。解消したら消す。

| 語                      | 場所                    | 直す先        |
| ----------------------- | ----------------------- | ------------- |
| AI プロファイル | `ai_library/profile.rs` ほかのコメント | 評価関数とプリセットのどちらを指すかを読み分ける |
| 断り | `ANALYSIS_REFUSAL` ほかのコメント（定義なし） | 定義をこの表の上へ足す |
| 口、門 | コメント全般（比喩） | 関数、経路、判定の語へ替える |
