調査レーン: OSINT L4 / 検証対象前提: **P-005「対象ユーザーは 50〜300 人規模」**
調査日: 2026-07-27（本文中の全数値は同日取得。API は当日実行）
手法: 受動的な公開情報の閲覧のみ。アカウント作成・ログイン・問い合わせ・フォロー等の能動的接触は一切行っていない。

## 結論（1段落）

推定の連鎖の**上流2段は観測に置き換わった**。「将棋人口430万人」は一次資料で定義まで確定でき（レジャー白書2025＝2024年調査、インターネット調査、有効回答3,467、「2024年に1回以上行った人」の割合4.4%）、同時にこの数字が**回答者約153人分の回答から全国推計されたもの**であり、研究家の density を一切含まないことが確定した。より近い代理指標として、現行の主要クロスプラットフォーム棋譜ツール **ShogiHome の GitHub Releases ダウンロード実数**を OS 別に取得した。ShogiHome は自動更新機構を持たない（`latest.yml` 資産なし・`autoUpdater` のコード出現 0 件）ため、**ダウンロード数は概ね人間の手動操作回数に対応する**。直近30日で 1,445 DL（win 983 / mac 269 / linux 193）、直近365日で 13,861 DL（mac 2,600）。macOS 比率は全期間・全窓で 16.7〜18.8% と極めて安定している。つまり**「保守されている棋譜研究ツールを実際に更新し続けている人口」は 10^3 のオーダー、その macOS 部分は 10^2 のオーダー**である。一方、有料転換率は公開情報からは一切観測できず、「50〜300人の有料ユーザ」の**下流1段は依然として未観測のまま**である。

## 判定: P-005「50〜300人」は **[判定不能]**（ただし上限300は観測と整合しにくい）

- **判定不能の理由**: 有料転換率を示す公開一次情報が存在しない。無料ツールのDL数から有料ユーザ数を導く観測可能な橋渡しがない。ここを推測で埋めることは本レーンの規律違反にあたるため埋めない。
- **ただし上限側について言えること（観測ベース）**: 同カテゴリで最も使われている無料ツール ShogiHome の **macOS ユーザ全体が1リリースあたり 269〜391 DL** である。obs-shogi が有料で 300 人を獲得することは、「カテゴリ首位の無料ツールの macOS 利用者ほぼ全数を有料転換する」ことに相当する。これは不可能とまでは言えないが、**上限300は観測されたカテゴリ規模に対して余裕がない**。
- **下限側（50人）は観測と矛盾しない。** 後述する「ShogiHome に4年3か月で公開の反応を返した外部の実在人物 = 42人」と同じオーダーである。
- **設計深度への含意**: 「名前の分かる20人向けに作る」という設計判断は、**観測によって否定されなかった**。むしろ「4年で42人しか公開の反応を返していない」という実測は、その設計深度を積極的に支持する。

当初「2025年以降に定跡・研究記事を3本以上公開している個人」と定義して note / ブログ / X を数え上げる計画だったが、**受動的閲覧のみという規律の下では機械的な網羅計数ができなかった**。理由:

### 「430万人」という数字そのものについて [重要]

**無償公開の一次資料に「430万人」という記載は存在しない。** 速報版詳細資料が公開しているのは**参加率 4.4%** までであり、人数への換算値は有償の書籍版『レジャー白書2025』にのみ掲載されている。

再現計算 [推定・算術のみ]: 4.4% × 15〜79歳人口（2024年、約9,800万人）≒ **431万人**。報道等の「430万人」と整合する。したがって数字自体は疑わしくないが、**「430万人・過去最低（レジャー白書2025）」を一次で引用したいなら書籍版の購入が必要**である。

### この数字が P-005 に対して持つ意味（本項の要点）

1. **母数は回答者約153人。** 4.4% × 有効回答3,467 ≒ **153人**。「将棋人口430万人」の全経験的基盤は、インターネットモニター3,467人のうち約153人が「2024年に1回以上将棋を指した」と回答したことである。将棋人口の**推定誤差は小さくない**し、まして「体系的な定跡研究家」の密度については**何一つ語っていない**。
2. **定義が極めて緩い。** 「年1回以上指した」に、正月に親戚と1局指した人が全員入る。これを研究家人口の出発点にすると必ず桁を誤る。
3. **年間平均費用 9.1千円。** これは参加者一人当たりの**将棋関連年間支出の平均**（書籍・盤駒・道場・オンライン課金等すべて込み）。有料アプリの価格設定に対する直接的な制約情報であり、本レーンで得られた**最も実務的な副産物**である。
4. **年間平均活動回数 18.1回。** 月1.5回。平均的な「将棋人口」は月1〜2回指す人であって、棋譜を溜めて研究する人ではない。分布はカジュアル層に完全に支配されている。
5. **緩やかな縮小は本物。** 参加率 4.8%→4.7%→4.4%、希望率 7.0%→5.8%→5.0%。希望率の低下幅（-2.0pt）が参加率の低下幅（-0.4pt）より大きく、**潜在需要も縮小している**。

## 未解決・人間に見てほしいこと

1. **【最優先・5分で終わる】r/shogi の実数を取ってほしい。** 本環境からは reddit が全経路でブロックされたが、ブラウザなら**ログイン不要**で `https://www.reddit.com/r/shogi/about.json` を開くだけで subscriber 数と active_user_count が取れる。海外の将棋研究層の規模を示す唯一の取り残しであり、obs-shogi が英語圏を射程に入れるかの判断に直結する。

2. **【判断が必要】『レジャー白書』書籍版（2025年10月31日発売）を買うか。** 買うと得られるもの: 将棋の人数換算値の一次確認、過去10年の時系列。買わない場合、無償速報版で 2022・2023・2024年の3点（参加率・回数・費用・希望率）まで取れているので、**実務上はこれで足りると考える。** 私見では**購入は不要**。

3. **【前提の書き換え提案】P-005 の書き方そのものを変えるべきだと考える。** 「対象ユーザーは50〜300人」は有料ユーザ数の推定であり、これは公開情報から**原理的に検証できない**（誰も公開していない）。検証可能な前提に置き換えることを提案する:
   - 旧: 「対象ユーザーは50〜300人規模」（検証不能）
   - 新案: 「**棋譜研究ツールを継続利用する母集団は 10^3 オーダー、うち macOS は 10^2 オーダー**」（ShogiHome DL数で毎月再検証可能）
   - こう書き換えると、**四半期ごとに `gh api` 一発で前提が生きているか確認できる**。P-005 を「観測で更新され続ける前提」に変えられる。

4. **【設計判断への含意・要確認】「名前の分かる20人向けに作る」は観測に否定されなかった。** ShogiHome は4年3か月で外部の実在人物42人しか公開の反応を返しておらず、watcher は2。**20人という設計深度は、観測された関与人口(42)と同じオーダーであり、妥当**と考える。ここは判断が変わらないことの確認であって、変更提案ではない。

5. **【価格設定への副産物・要検討】将棋参加者の年間平均支出は 9,100円（2024年、一次確定）。** 盤駒・書籍・道場・オンライン課金すべて込みの平均。研究家層はこれより高いはずだが、**分布の中心が年間1万円弱**である事実は、有料化する場合の価格帯（買い切りか、月額いくらか）に直接効く。本レーンの想定外の収穫であり、価格を議論する際に参照されたい。

6. **【トレンドの注意喚起】隣接する開発者コミュニティは縮小している。** WCSC 参加チーム 42(2021)→35(2025)、-17%。将棋参加率 4.8%→4.4%、希望率 7.0%→5.0%。**希望率の下落幅が参加率の下落幅を上回っており、潜在需要も縮小している。** obs-shogi の母集団は今後**拡大しない**前提で計画するのが妥当と考える。

7. **【残タスク・人間レーン】「継続的に定跡研究を発信している個人」の数え上げ。** 本レーンでは認証要件により機械的な網羅計数ができなかった。もし数えるなら、プラットフォームを note.com に絞り、「2025年以降に将棋の定跡・研究記事を3本以上」という定義で手作業で数えるのが現実的。ただし**この数字が意思決定を変えるかは疑問**で、優先度は低いと考える（上記1の方が費用対効果が高い）。
