# ShogiGUI

- 立場: 閉じた GUI。検討機能の代表。Windows（Mono で Linux も可）
- 版: 配布ページの最新は 0.0.8.8（2026/7/1）。**マニュアルはそれより古い**（必要環境の記述が .NET 4.5 のまま。トップは 4.8.1）
- 取得日: 2026-10-31
- 取り方: 公式マニュアルのみ。URL は `README.md`。**実機では確かめていない**
- 等級: **公式の文面そのものは `[確定]`**、そこから読み取ったものは `[推定]`（根拠を併記）。
  **公式の文面に無いことは「公式の文面に無い」と書き、推測で埋めない。**
- **大きな穴: マニュアルの説明の多くは画面写真の中にあり、写真の大半を取得できなかった**（`README.md` の「調べ切れなかったこと」）。
  したがって下の「公式の文面に無い」は**本文に無い**という意味で、**写真の中に書かれている可能性が残る。**
  読めた写真は5枚（エラーダイアログ、エンジン一覧2枚、対局ダイアログ、コメント（思考）ウインドウ）
- 探索の範囲: マニュアルの本文（将棋エンジン設定 / ツールメニュー エンジン設定 / 検討設定 / オプション / 対局設定 / 検討 / 棋譜解析 / 定跡 / 思考ウインドウ / ユーザーインターフェース / ヒント、詰み探索 / アシスタント）、`manuals/consider_multi.html`、よくある質問の 2020-10-21 の写し

略記: `エンジン設定` = マニュアル「将棋エンジン設定」、`検討` = マニュアル「検討」、`複数` = `manuals/consider_multi.html`、`FAQ` = よくある質問（Internet Archive の写し）
