# モーダル

状態：確定（v0.3、decisions/0005）。製品に入れた（2026-11-23）
トークン：`radius.modal`、`shadow.overlay`、`color.border.default`、`color.background.default`

## 用途

いまの作業をいったん止めて、1つのことを済ませる。設定、局面検索、確認。

## 使わない場面

- 作業を続けながら見るもの → 付箋、ポップオーバー、ドックのタブ

## 組み立て

- 本体は1枚。背景は `color.background.default`、枠は `color.border.default`、角は `radius.modal`、影は `shadow.overlay`。**中に枠のある箱を入れない**
- 題は `font.size.section` の `font.weight.title`。題と中身の境は線。長い題は折る
- 中身だけを送る。題と、下の押すものは動かさない（製品の `ModalHead` と `ModalFoot`）
- 2つに分けるときは、境の線1本。左に一覧か局面、右に詳細か欄
- 押すものは右下に、キャンセル、確定の順。確定は1つ（`button.md`）。取り消せない操作は左下
- 高さは中身に合わせ、ウィンドウの高さから余白を引いた値で止める

## 状態

待ち・失敗は、モーダルの中の、押したものの近くに出す。閉じて知らせない。

## アクセシビリティ

開いたら中へ、閉じたら開いた所へフォーカスを返す。開いたときの行き先は、書く欄があれば最初の欄、タブなら見ているタブ、一覧が主役なら全体（輪を押すものに出さない）。開いた所が消えていたら、その場所を含む一覧へ返す。
