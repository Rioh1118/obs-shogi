# コンポーネント選定索引

「こういう場面ではどれを使うか」を引く表。部品を選ぶときに最初に読む。各部品の詳細は同じフォルダの `<名前>.md`。

状態：基準線（v0.1）。製品の今の規則（製品の `docs/spec/design-language.md` §5「部品の選び方」、2026-11-08）から写した。文書があるのは Button だけで、他の部品は製品側に実装があり、文書はまだ無い（工程5で画面ごとに足す）。

**部品は入力の種類で決める。同じ種類を別の部品にしない。**

| 場面 | 使う部品 | 使い分けの条件 | 使わない部品 | 詳細 |
| --- | --- | --- | --- | --- |
| 2〜4の択一 | 区切りボタン | 全部見えて1回で変えられる | 選択、ラジオの縦並び | 未作成 |
| 5つ以上の択一 | 選択 | 選択肢が多い・増える | 区切りボタン | 未作成 |
| 数 | 数の欄と増減 | 範囲と段階が決まるなら、つまみを欄の下に足す。**欄が正** | つまみだけ | 未作成 |
| 文字 | 文字の欄 | — | — | 未作成 |
| パス | 文字の欄と「選択…」のボタン | 選べなくても打てる | ボタンだけ | 未作成 |
| 操作を実行する | Button | 役割で選ぶ（確定・進める・中立・危険） | リンクの見た目のボタン | [button.md](button.md) |

## 並ぶ部品の共通の基準

**同じ行に並ぶ部品は、別の高さや枠を持たない。** 値は Button に揃える。

| 項目 | 基準 |
| --- | --- |
| 高さ | sm 28px / md 32px / lg 40px。**フォームの行は md** |
| 角丸 | `radius.control` |
| 枠 | `color.border.default`。打つ欄の背景は `color.surface.field` |
| 文字 | 押すものは `font.size.aux` の `font.weight.strong`。打つ欄は `font.size.body` の `font.weight.regular` |
| 無効 | 不透明度を下げるだけ（0.45）。色を変えない |
| フォーカス | 固定のリング（`focus.ring.*`）。枠の中で切れる部品は外側のコンテナに出す |
| 不正 | 枠は `color.feedback.danger.default`、文字は `color.feedback.danger.text` |
| つまみ | 軌道 4px、満たした側は `color.accent.default`、持ち手は `color.text.default`。ブラウザ既定のまま出さない |
| 幅 | 押すものは文字の幅。**行の余りを押すもので埋めない。** 余りは入力欄が受け持つ（利用者、2026-10-31） |
| 記号 | アイコンの集合1つ（製品では `lucide-react`）。増減も記号で、文字で代用しない |
