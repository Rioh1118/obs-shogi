# 設定の行

状態：確定（v0.3、decisions/0005）。製品に入れた（2026-11-23）
トークン：`color.text.*`、`color.border.weak`、`font.size.*`

## 用途

設定の1つの話題を、見出しと行で並べる。

## 使わない場面

- 1回限りの確認 → モーダル
- 増える一覧 → 一覧の行（`list-row.md`）

## 組み立て

- 話題ごとに見出し（`font.size.section` の `font.weight.strong`）。話題の境は `color.border.weak` の線と余白。**箱で囲まない**
- 1行は、左に名前、右に欄か押すもの。説明は名前の下に `font.size.aux` で
- 値だけを見せるときは、名前（`color.text.faint`）の下に値（`color.text.strong`）
- **数の決まった設定を上、増える一覧を下に置く。** 一覧は自分の中で送り、上の設定を動かさない（利用者、2026-11-23）
- 済んでいる説明（セットアップの手順など）は閉じておく。やり残しがあるときだけ開く

## 状態

- うまくいっている間は何も言わない。「設定済み」の札を出さない
- 直さないと動かないときだけ、その話題に語（`color.feedback.warning.default`）と次の一手。左の一覧には ⚠ を1つ

## アクセシビリティ

名前と欄を結ぶ。説明は欄の説明として結ぶ。

## 文言

欄の名前は体言。説明は1文。
