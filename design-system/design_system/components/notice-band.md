# 知らせの帯

状態：確定（v0.3、decisions/0005）。製品に入れた（2026-11-23）
トークン：`color.feedback.*.surface`、`color.feedback.*`、`color.border.weak`

## 用途

残る知らせ（失敗と、消えない警告）を、上の帯の下に1件1行で出す。

## 使わない場面

- うまくいったこと → 出さない
- その場の欄の不正 → 欄の下
- 取り消せない操作の確認 → モーダル

## 組み立て

- 1行 34px。左から、記号・何が起きたか・次にすること（押すもの）・詳細・閉じる
- **2件まで。** 3件目からは「ほか n 件」で、押すと並ぶ
- 詳細は押したときだけ、行の下に開く。1行で言い切れるなら付けない
- 進んでいる最中（更新の取得、入れ替え）は、閉じるを出さない。進み具合は細い線
- 置き場は本文の上。**右下に浮かせない。** 操作と本文を覆う
- 帯のぶんの高さは、ドックから取る。盤の大きさを変えない

## 状態

tier と色は `patterns/status-and-feedback.md`。背景は `color.feedback.*.surface`、記号と語は tier の色、文は `color.text.default`。

## アクセシビリティ

失敗は警告の役、伝えるだけのものは状態の役を名乗る。閉じるボタンの名前に、何を閉じるかを入れる。

## 文言

「何が起きたか。次にすること。」の2文（`content/voice-and-tone.md`）。
