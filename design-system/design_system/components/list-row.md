# 一覧の行

状態：規則は確定（v0.3、decisions/0005）。製品の実装は画面ごとに入れる
トークン：`color.background.*`、`color.border.weak`、`radius.row`

## 用途

同じ種類のものを縦に並べる。棋譜の手、ツリー、プリセット、検索の結果、メニューの項目。

## 使わない場面

- 1件が画面の半分を占めるもの → 見出しと中身で組む
- 2〜4の択一 → 区切りボタン

## 大きさ

| 一覧 | 行の高さ |
| --- | --- |
| 棋譜、ツリー、表（候補手・定跡） | 26px |
| メニュー | 28px |
| 2段まで折る行（プリセット、検索の結果） | 40px から、中身に合わせて伸びる |

行の角は立てる（`radius.row`）。行と行の間は空けず、分けるときは `color.border.weak` の線。

## 中身

- 名前を先に、数と状態を右に揃える。数は桁で揃える
- 長い名前は、1行の一覧なら末尾を省き、2段まで折る一覧なら折り返す。**途中を省かない。** 別のものが同じ表示になる
- 行の操作（分岐、コメント、編集、削除）は右端。行の高さを変えない

## 状態

選択・いま・ホバー・フォーカスは `patterns/selection.md`。無効は不透明度 0.45。

## アクセシビリティ

- 操作のあるボタンを持つ行は、行とセルの役を名乗る。選択肢だけの一覧は、選択肢の役を名乗る
- 行に載る文字は、選んだ行の上でも 4.5:1 以上（`color.text.faint` は選んだ行に載せない）

## 文言

空のときは、理由と次の一手（`patterns/status-and-feedback.md`）。
