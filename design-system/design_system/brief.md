## 1. 何のための UI か
- 製品・サイトの一文説明: 将棋の棋譜とエンジンの読みを並べて研究するデスクトップアプリ（Tauri。macOS / Windows / Linux）
- 主な画面（3つ）: 盤・駒台・棋譜ストリームと検討ペインの主画面 / 設定とエンジンのプリセット編集 / 局面検索・課題局面のモーダル
- 使われる環境: PC 中心。ダークのみ（今の画面に明るいテーマは無い）。長時間、盤と読み筋を見比べる

## 2. 誰が使うか
- 主な利用者と、その人がその画面でやりたいこと:
  - 将棋 AI の開発者: エンジンの読み・定跡を局面ごとに確かめる（利用者、2026-08-29 に軸として明示）
  - 棋譜を研究する人: 棋譜を読み、変化を足し、局面を課題として残す
- **洗練されたと言えれば成功、と判定する目: 棋譜を研究する人**（利用者、2026-11-08 の回答）。AI 開発者は製品の機能の軸として残る
- 配慮が必要なこと: 業務で長時間使う。数字（評価値・深さ・ノード数）を比べる。盤から目を離さずに読む

## 3. コンセプト
- 一文で: 開発者の道具の精度で、タイトル戦で使われるような本物の盤と駒台を囲む研究の机
- キーワード候補: スタイリッシュ / 洗練 / 研究（利用者、2026-11-08）

       例）「町の写真館の封筒」「方眼紙」「晴れた日の駅の案内板」 -->
- キーワード（3〜5個。形容詞だけでなく、物・場所・素材も入れる）: 開発者の道具（IDE・計器） / タイトル戦の盤駒（本物の木） / リッチ / authentic / 研究
- そのキーワードを選んだ理由: 利用者の回答（2026-11-08）「開発者の道具（IDE・計器）。盤と駒台の画像は authentic というかタイトル戦で使われるような素材、木の画像。そういうリッチで authentic な感じ」。枠は道具の精度（検討ドックが理想の見本）、素材は本物の木。この2つの対比が今のスタイリッシュさの元になっている

## 6. 既に決まっているもの（変えられないもの）
- **盤・駒台・駒は実物の画像。** 榧の盤と濃い木の駒台。トークンの対象外で、テーマの色はこの画像から逆算する。盤を平らな色で描く案は却下済み（利用者、2026-10-31 と 2026-11-08）
- **素材と枠の2層。** 枠は素材を引き立てる側に回り、自分で質感を主張しない。枠に木目や装飾を足さない

## 8. 文言の声
- 敬体 / 常体、一人称、呼びかけ方: 文は です・ます。状態の語・欄の名前・ボタンは句点なし。一人称と呼びかけは使わない。標準的な業務アプリの日本語で、言い回しで個性を出さない（利用者、2026-10-31）
- エラー文の例（1文）: 棋譜を読み込めませんでした。ファイルの形式を確認してください。
- ボタン文言の形: 漢語は体言止め（「保存」「削除」）、和語は言い切り（「開く」「閉じる」）。「〜する」を付けない（利用者、2026-10-31）

## 9. 成功の基準
- このデザインシステムがうまくいったと言える状態（人が判断する項目）:
  - 棋譜を研究する人が見て「洗練された」と言える。今のイメージ（暗い枠・砂色の文字・銅・本物の木）が保たれている
  - 検討のドックと候補手のパネルの質が、サイドバー・最初の画面・ローディング・設定・モーダルにも揃っている
  - 同じ役割の部品が画面ごとに別の見た目を持たない
  - 盤と駒台の画像が枠の色に負けず、いちばんリッチに見える
