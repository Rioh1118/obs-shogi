# patterns/

画面の組み立て方（フォーム、エラー、空状態、レイアウト）を、選定条件つきで書く場所。新しいパターンは `_template.md` を写して作る。

| パターン | 状態 | 何を決めるか |
| --- | --- | --- |
| [status-and-feedback.md](status-and-feedback.md) | 基準線 | 状態・成功・空・待ち・失敗の見せ方。意味色の tier |
| [selection.md](selection.md) | 基準線 | 選ばれている行・項目の見せ方 |

まだ決まっていないこと（製品の `docs/spec/design-language.md` §7 から移した問い）:

- **空状態 / 読み込み中 / エラー表示を共通の部品にするか。** 決めるときは「どこに出すか」（トースト / ペイン内 / モーダル）と「復帰の導線を持たせるか」まで含める。エラーを出しても復帰の導線が無ければ行き止まりになる
- **どのレベルがスクロールを受け持つか。** 長い文字列（棋譜のコメント、ファイル名、エンジン名、エラー）は省略か折り返しか。1つに決める
- **幅が狭いときのレイアウト。** 盤をどう縮め、横の面をどこへ逃がすか。製品の対象は今は幅 1280px 以上で、下限を決め直す（製品の移行計画の工程6）
