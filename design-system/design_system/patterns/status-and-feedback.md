# 状態と失敗の見せ方

状態：基準線（v0.1。製品の `docs/spec/design-language.md` §3・§5 と ADR-0004 から写した）
関連する部品：Button、帯（製品側に実装あり、文書は未作成）、待ちの表示（製品の `Spinner`）

## いつ使うか

処理の状態（待ち・成功・失敗）と、中身が無い状態を利用者に伝えるとき。

## いつ使わないか

- うまくいった段階を知らせたいとき。**成功は出さない。** 読み込み・確かめ・当てる、は成功したら黙る（利用者「内部の段が画面に出て分かりにくい」、2026-09-30）
- まず起きないことに備えるとき。常設の段や行を足さない（利用者、2026-10-31）

## 仕組み

### 状態は語で言う

- **いまの状態は語で言う。** 色と記号は語を支えるだけで、語を置き換えない
- **帯を閉じても状態の語は残る。** 帯は知らせるもので、状態そのものではない
- **起きたときだけ、既存の場所の語とボタンが変わる。** 文は帯が持つ

### 空

**理由と次の一手を言う。**「何もありません」で終えない。次の一手のボタンを同じ場所に置く。

### 待ち

**何を待っているかを言い、長引いたら中止の操作を出す。** 中止できない待ちを作らない。反復して動いてよいのは待ちの表示だけ。

### 古い結果

**古いと書く。** 消すか、いつのものかを添える。今のもののように並べない。

### 失敗の tier

tier は**深刻度ではなく「復帰に何が要るか」**で切る。見た目の派手さで選ばない。成功の色は置かない。

| tier | 復帰に要るもの | 色のトークン |
| --- | --- | --- |
| info | 何も要らない。伝えるだけ | `color.feedback.info.*` |
| warning | もう一度で直る | `color.feedback.warning.*` |
| danger | 別の操作が要る。危険な操作の確認もここ | `color.feedback.danger.*` |
| fatal | アプリの再起動 | `color.feedback.fatal.*` |

- **tier の区別を色だけに持たせない。** danger と fatal の文字の色は、暗い背景で基準まで持ち上げると必然的に寄る。区別は記号と文言、そして出す動作（「アプリを再起動」）が持つ
- 背景に敷くなら `*.solid` か `*.surface`、暗い背景に載る文字なら `*.text`。失敗を伝える箱の背景（`*.surface`）は不透明にする。載る場所ごとに実効値が変わるのを防ぐため
- 通知はモーダルより上に重ねる（`z.notification`）。下にするとぼかされて読めず、クリックがモーダルを閉じて入力が消える

## 文言

`content/voice-and-tone.md` のトーンの表。失敗は「何が起きたか。次にすること。」の2文、`〜できませんでした。` に揃える。待ちは `〜しています…`。

## アクセシビリティ

- 状態の語は色に頼らない（上の「語で言う」）
- 失敗の文字の色は `contrast-pairs.json` で 4.5:1 を照合している
