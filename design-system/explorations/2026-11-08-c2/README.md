# C2 面を1色に、盤だけ沈める

案（モード B、2026-11-08）。本体には混ぜない。選ばれたらモード C で本体へ反映し、この案は残す。

## 1. 名前とコンセプト

**C2 面を1色に、盤だけ沈める**：C の色と形のまま、サイドバー・棋譜・ヘッダ・ドックを同じ1色の面にし、線で区切る。盤の周りだけを一段沈めて盤を浮かせる。

brief の解釈：C と同じ。加えて、ペインを色で塗り分けない（利用者「サイドバーと棋譜の色を分けているのがダサい」、2026-11-08）

## 2. 具体的な参照

1枚の暗いパネルに、細い線で区切った計器が並んでいる。中央の窪みにだけ盤が置かれている。

## 3. カラー

| 名前 | 値 | 役割 |
| --- | --- | --- |
| 深い面（`color.background.sunken`） | `#121819` | サイドバー、暗いカード |
| 本文の背景（`color.background.default`） | `#1b2325` | ドック、ヘッダ、モーダル |
| 棋譜の面（`color.background.canvas`） | `#253033` | 棋譜ペイン、選ばれた行の濃淡 |
| 盤の面（`color.background.stage`） | `#0f1415` | 盤と駒台の周り |
| 砂（`color.text.default` / `color.commit.solid`） | `#d8dbd3` | 本文、確定のボタン |
| 銅（`color.accent.default`） | `#a8805f` | 選択の棒、目印、銅の文字は `#c8a07c` |
| 危険（`color.feedback.danger.*`） | `#b5645c` | 本体と同じ |

盤の面：盤の周りだけをいちばん深い色（#0f1415）にする。他のペインは全部 `color.background.default`（#1b2325）で、境目は線

主要な組み合わせのコントラスト比は `npm run ds:check -- --dir explorations/2026-11-08-c2` の出力（このディレクトリの README の末尾に写した）。説明文の色は `#b2b6b0`。

## 4. タイポグラフィ

- 本文：`font.family.sans`（端末の和文ゴシック）。大きさの段階は本体と同じ（hint 11 / aux 12 / body 13 / lead 14 / section 16 / title 18 / display 24 / hero 40px）。太さも本体と同じ4段
- 題（`font.family.heading`）：system-ui, Hiragino Sans …
- 見出しと注記（`font.family.label`）：ui-monospace, SFMono-Regular …
- 行間：表と一覧は詰める。長い文だけ `font.lineHeight.body`（1.5）

## 5. 密度と形

- 余白：本体と同じ 2px 刻み
- コントロールの高さ：本体と同じ（sm 28 / md 32 / lg 40px）
- 角丸の役割：行 `radius.1` / 押すもの `radius.2` / 面 `radius.2` / モーダル `radius.3`
- 影：面は影で浮かせず線で区切る。ポップオーバーだけ影

## 6. 文言の声

3案で同じ（本体の content/）。ボタン「保存」、失敗「棋譜を読み込めませんでした。ファイルの形式を確認してください。」、空「棋譜を選択するか、作成してください」。

## 7. 見本

`index.html`。3画面（主画面、プリセット編集、課題局面）を全案で同じ内容で並べた。盤と駒台は実物の画像（`../2026-11-08-assets/`）。

## 8. トークン案

`tokens/`（本体と同じ名前の体系。足したのは `color.background.stage`、`font.family.heading`、`font.family.label`）。

## 9. Do's and Don'ts

- Do: 検討のドックと候補手のパネルは、色以外を本体のまま残す
- Do: 盤の面は1色に決め、他の面と混ぜない
- Do: 選択は左の銅の棒1通りで見せる
- Don't: 盤と駒台を平らな色や別の画像にする
- Don't: 枠に木目・和柄・グラデーションを足す
- Don't: 面の暗さを4段以上にする

## 10. リスクと弱点

ペインの境目が線だけになるので、どこまでがサイドバーかの手掛かりが弱くなる。盤の周りの窪みが1つだけ残る

## 今の値から直したところ

色の値は案の方向に合わせて全体を動かしたので、今の製品にあった不足（説明文 × 棋譜の面、失敗の文字 × 本文の背景）は、この案の値では起きない。
