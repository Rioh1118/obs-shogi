# D 計器の枠と木の場

案（モード B、2026-11-08）。本体には混ぜない。選ばれたらモード C で本体へ反映し、この案は残す。

## 1. 名前とコンセプト

**D 計器の枠と木の場**：枠・ドック・見出しは C の計器の精度にし、盤と駒台の周りだけを B の焦げ茶にする。開発者の道具の中に、タイトル戦の盤駒の場が1つある。

brief の解釈：スタイリッシュ＝冷たい道具と温かい木の対比／洗練＝道具の側を線と等幅で整列させる／研究＝検討ドックの表の性格を枠全体へ。authentic＝盤の場だけが木の色温度を持つ

## 2. 具体的な参照

暗いテーマの IDE のパネルの中に、照明を落とした対局室の一角がはめ込まれている。道具の側は線と等幅で整列し、盤の側だけが木の色温度を持つ。

## 4. タイポグラフィ

- 本文：`font.family.sans`（端末の和文ゴシック）。大きさの段階は本体と同じ（hint 11 / aux 12 / body 13 / lead 14 / section 16 / title 18 / display 24 / hero 40px）。太さも本体と同じ4段
- 題（`font.family.heading`）：system-ui, Hiragino Sans …
- 見出しと注記（`font.family.label`）：ui-monospace, SFMono-Regular …
- 行間：表と一覧は詰める。長い文だけ `font.lineHeight.body`（1.5）

## 5. 密度と形

- 余白：本体と同じ 2px 刻み
- コントロールの高さ：本体と同じ（sm 28 / md 32 / lg 40px）
- 角丸の役割：行 `radius.1` / 押すもの `radius.2` / 面 `radius.2` / モーダル `radius.3`
- 影：面は影で浮かせず線で区切る。ポップオーバーだけ影

## 9. Do's and Don'ts

- Do: 検討のドックと候補手のパネルは、色以外を本体のまま残す
- Do: 盤の面は1色に決め、他の面と混ぜない
- Do: 選択は左の銅の棒1通りで見せる
- Don't: 盤と駒台を平らな色や別の画像にする
- Don't: 枠に木目・和柄・グラデーションを足す
- Don't: 面の暗さを4段以上にする

## 10. リスクと弱点

冷たい枠と温かい場の境目が目立つ。場の色が枠のどの面とも違うので、面の色が1つ増える（4つ目の面になる。今の『盤の周りが4つ目の暗さ』と同じ形の弱点を、意図して持つ）。等幅の見出しは日本語で間延びしやすい（C と同じ）

## 今の値から直したところ

色の値は案の方向に合わせて全体を動かしたので、今の製品にあった不足（説明文 × 棋譜の面、失敗の文字 × 本文の背景）は、この案の値では起きない。
